# 創作桌（原型第五版）

試玩：https://claude.ai/artifact/4E19mddVQPmLQFxw6CeJ1U

製作人上載了全部素材（畫 216 張、Flow Music 47 首）之後的版本：**玩家打出的每一張卡，都是真的畫的一格、真的歌的一小節。**

第一至四版（`proto/night/` 至 `proto/night4/`）保留不變。

## 一、創作桌的機制

核心規則沿用第四版（起承轉合、複合情緒、題材、難題、提示、夥伴、進修、改造），這一版改的是「打牌的結果是甚麼」。

| 你做的事 | 畫 | 歌 | 分數 |
|---|---|---|---|
| 第一筆 | 天空（主調的情緒；有「轉」是戲劇性的版本）和兩排遠景 | 一段：每張素材一小節 | 起承轉合的結構 |
| 第二筆 | 海上的建築：起、轉、合三座，有倒影和燈影 | 同上 | 同上 |
| 第三筆 | 碼頭上一排小場景：起、轉、合三格，加上出過手的夥伴 | 同上 | 同上 |
| 第四筆 | 前景框 | 同上 | 同上 |
| 「轉」 | 那一格放大、有聚光 | 屬和弦，想回家 | ×2 |
| 「合」 | 全畫的燈更亮 | 回到主和弦，有重擊 | ×2 |
| 三筆完整的起承轉合 | 整幅畫裱金框 | | |
| 具名組合 | 名作插畫整幅揭曉，收進圖鑑 | | 組合的加成 |

這一版新加的規則：

- **卡面就是畫**：75 張素材各有自己的卡面。一種情緒的卡是「主角」，兩種情緒的卡是「小景」。打出去，卡面就出現在畫裏。
- **平衡的牌組**（`deck.js`）：十種情緒各三張單一素材，45 種組合各一張。
  - 主遊戲的素材卡不再出現：138 張裏只有 1 張帶愧疚，13 種組合沒有卡。
  - 起手是十種情緒各一張，加上主角帶來的四張複合情緒，再補七張常見素材。
- **達標之後繼續畫**：分數到了目標只蓋「達標」印，要用完所有筆才收工。
  - 達標之後每一筆是「加演」，火花 +0.1。
  - 原因：第四版高手一、兩筆就過關，畫只畫了一半。
- **圖鑑**（存在這部裝置，跨局累積）：45 種複合情緒、40 個名作。
  - 卡上標「新」＝ 圖鑑未有。
  - 收工的三張新素材裏，至少兩張是圖鑑未發現的組合。
- **差一張的提示**：稿紙上的素材再加一種情緒就是名作時，提示缺哪一種；未收藏的名作優先。
- **目標重新校準**：10,000、30,000、55,000。平衡的牌組情緒分散，分數比第四版低。

| 模擬玩家（每筆隨機試的次序） | 第一晚 | 第二晚 | 第三晚 |
|---|---|---|---|
| 6 個 | 50% | 14% | 4% |
| 25 個（三位主角） | 86–96% | 55–84% | 38–45% |
| 120 個 | 100% | 93% | 80% |

## 二、畫（`painter.js`）

做法和 `tools/art-night-compose.py` 相同，在瀏覽器即時組合，畫布 960×600：

- 發光的像素由程式找出來，縮到四分之一再放大成光暈；中景的燈在水面有長影。
- 倒影、天色在水面的倒影、水波（水面按行移動）、霓虹呼吸和閃爍、雨夜的雨。
- 建築和前排按天空的平均色統一色調。
- 素材用到才載入；同一張卡永遠是同一張圖、同一個方向。

素材由 `tools/art-night-web.py` 轉成 WebP（212 張，20 MB；組畫用的約 6 MB）。

## 三、歌（`music.js`）

做法和 `tools/music-night-preview.py` 相同，用 WebAudio 播放製作人的分軌：

- **母曲**（`base`）是那一晚的樂隊。起承轉合決定和弦功能（起、合 = I；承 = ii、iii、vi、IV；轉 = V），程式在母曲裏找一條盡量連續的小節路徑。
- **層**：卡的媒材決定哪件樂器出場，按和弦配對整句。

| 媒材 | 樂器 |
|---|---|
| 聲 | 那種情緒的主旋律（十種） |
| 紙 | 人聲（city pop 未有人聲，暫時用弦樂） |
| 身 | 敲擊 |
| 數 | 琶音 |
| 影 | 弦樂 |

- 選牌時母曲隔着牆（低通）做背景；計分時每張素材奏半小節，樂隊逐層加入；收工後播放完整的歌，最後有掌聲。
- 分軌用到才下載和解碼，層最多留 8 條在記憶體。

分軌的處理：

1. `tools/music-build.py`：變速到同一個 BPM、移調到母曲的調、按鼓點對齊、逐小節標和弦。
2. `tools/music-night-web.py`：每首挑最好的一段 24 小節，統一響度，轉成 MP3（共 29.5 MB，每晚只載入一種風格）。

模擬 300 筆：每張素材配得到一小節的比例，各種媒材都在 79% 以上；母曲的路徑有 62–77% 是原曲連續的小節。

**未驗證的地方**：我沒有辦法親耳聽。移調幅度大的分軌（最多 6 個半音）音色可能不自然，要製作人試聽。

## 四、一步步令遊戲更上癮

每一步只加一個「想再玩一局」的理由，做完試玩才做下一步。

| 步 | 內容 | 上癮的來源 | 狀態 |
|---|---|---|---|
| 1 | 卡面就是畫；名作揭曉；圖鑑；「新」的標記；差一張的提示 | 收集、差一點就成功 | 這一版 |
| 2 | 傳說名作 18 張在創作之夜的條件（例如一晚四筆都完整、一筆用齊五種媒材、十種情緒都在一晚出現） | 長線的目標 | 下一步 |
| 3 | 每日題目：全部玩家同一副牌、同一位評審，比較作品和分數 | 每天回來、和朋友比較 | |
| 4 | 作品存成圖片（標題、簽名、金框）和分享頁 | 炫耀 | |
| 5 | 牌組的流派：夥伴和進修之外，加「畫風」（例如雨夜派：水的素材令全畫下雨，倍率跟雨有關） | 每局不同的打法 | |
| 6 | 展覽：三晚的作品掛在會場（用觀眾、欄杆的前景），外星評審逐幅評語 | 一局的高潮 | |
| 7 | 搬回主遊戲（`game/`），寫第十六期的工單 | | 製作人給 5 分以上之後 |

## 五、檔案

| 檔案 | 內容 |
|---|---|
| `deck.js` | 75 張素材的牌組和卡面 |
| `engine.js` | 規則（第四版加上：平衡牌組的目標、達標後繼續、獎勵優先給未發現的組合） |
| `painter.js` | 用素材即時組畫 |
| `music.js` | 用分軌按起承轉合編歌 |
| `night.js`、`night.css`、`index.html`、`sfx.js` | 畫面：卡面、名作揭曉、圖鑑、提示 |
| `build.js` | 打包：`node proto/night5/build.js <輸出檔> --art <素材資料夾> --music <分軌資料夾> [--share 連結]` |

素材和分軌不入 git（太大），由原圖重新生成：

```bash
python3 tools/art-night-web.py <原圖資料夾> <輸出>/art
```

```bash
python3 tools/music-night-web.py <music-build 的輸出> <輸出>/music
```

原型不改 `game/`，舊模式和五輪模式完全不受影響。
