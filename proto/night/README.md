# 創作之夜：「一晚」的好玩性原型

製作人在 2026-11-03 試玩 v3.0 之後，給遊戲的好玩度打了 1 分（滿分 10）。這個原型只做創作之夜，用來找出好玩的地方，目標是 5 分以上。
找到好玩之前，不寫新的 Gemini 工單；確定之後，再把做法搬回 `game/`，並且寫成第十六期的工單。

## 玩法

- 一局共三晚：社區小展、畫廊聯展、外星評審。三晚的目標分數是 3,000、5,500 和 8,000。
- 每晚的資源：手牌 8 張、4 筆、改稿 3 次，一筆最多放 5 張素材。
- 素材的情緒在色輪上連成形狀，形狀決定基本的籌碼和倍率；遊戲不會預先算出分數。
- 下筆之後的演出順序：
  1. 每張計分的素材逐張畫上畫布，同時加入它的籌碼；
  2. 靈感物件觸發，評審的規則生效；
  3. 觸發具名組合；
  4. 顯示算式並數出這一筆的分數。
- 評審：每晚一位外星評審（保育者、章魚星人、菌絲網絡或灰人），各有一條規則和一項委託。
  - 委託是一個具名組合。評審只公開它的名字和情緒的數目，玩家要自己猜是哪幾種情緒。
  - 完成委託：那一筆的倍率 ×2，收工時火花 +0.2。
- 收工：
  - 這一晚的畫掛上作品牆，題目取自具名組合或最主要的情緒。
  - 火花獎勵：每剩一筆 +0.1；分數達到目標的兩倍 +0.2；完成委託 +0.2。
  - 從三件靈感物件中選一件，再從三張素材中選一張。
- 失敗：可以重畫這一晚，或者從第一晚重新開始。

## 和遊戲規則的差別

- 全光譜要 9 種或以上的情緒，遊戲是 8 種。原型提高門檻，是因為大部分素材有兩種情緒，五張很容易湊到 8 種，全光譜會變成最容易的高分配色。
- 具名組合要配色成形才成立，草稿不算。唯一的例外是評審的委託：委託只看內容，草稿也算；但在灰人的「標準化」規則下，草稿一律不計分。
- 靈感物件的名稱、說明和圖示取自 `D.OBJ`，效果在 `engine.js` 的 `OBJFX` 重新實作，只收入計分時會觸發的物件。
- 牌組的組成：文案的背景卡、`D.STARTER`，再隨機加 7 張常見素材。火花由背景決定（文案是 2.4）。

## 檔案

| 檔案 | 內容 |
|---|---|
| `engine.js` | 規則（純邏輯，瀏覽器和 Node 共用）：配色、計分步驟、評審、委託、獎勵 |
| `painter.js` | 畫布（320×200 像素）：構圖由配色決定，顏色由情緒決定，筆觸由媒材決定 |
| `sfx.js` | 音效（WebAudio 即時合成） |
| `night.js` | 畫面和演出 |
| `night.css`、`index.html` | 樣式和開發版頁面（直接用瀏覽器開啟，讀 `../../game/js/` 的資料檔） |
| `build.js` | 打包成 Artifact 格式的單一檔案：`node proto/night/build.js [輸出檔]`，背景音樂複製到輸出檔旁邊的 `audio/` |

原型不改 `game/`，舊模式和五輪模式完全不受影響。
