# 創作之夜・難題（原型第四版）

## 為甚麼做第四版

製作人試玩第三版之後的意見：

1. **玩法**
   - 單一情緒的素材（例如「希望」）可以用提示，看它能接哪幾張，提示有次數限制。
   - 繼續研究現在的系統，令好玩度和豐富度提升。
   - 目標分數要提高很多；每一關都要有難題，好像 Balatro 的 Boss。
2. **標籤系統**：方向對，要繼續深入打磨。
3. **畫和歌**：有進步，但仍然很初步，只有 3 分（10 分滿分）。要提升到真正搞音樂、繪畫的人都不敢看小。
4. **全部都要改進。**

第一至三版（`proto/night/`、`proto/night2/`、`proto/night3/`）保留不變，方便比較。

## 玩法的改變

### 每晚的難題

評審的性格決定難題，每晚隨機抽一個：

| 評審 | 可能的難題 |
|---|---|
| 保育者 | 開場冷場（起不計籌碼）、預算削減（手牌 7 張）、不准刺激（轉不加倍） |
| 章魚星人 | 拒絕重複（相同情緒的承不加倍率）、團友搗亂（每筆之後隨機拿走兩張）、矇眼（某種情緒看不見標籤） |
| 菌絲網絡 | 樣本要多（少於 5 張分數減半）、分解（複合情緒不觸發）、篇幅限制（一筆最多 4 張） |
| 灰人 | KPI（沒有合不計分）、效率審查（只有 3 筆）、通脹（籌碼減半）、一稿過（不能改稿）、去個人化（題材加成不計） |

評審原本的「規則」改為「喜好」，是正面的加成。灰人之夜例外，喜好也是反面的。

### 提示

每晚 3 次。在稿紙上放了素材之後按「提示」：
- 手上每張素材會標出接在最後一張後面的效果：「承 +2」「承 +1」「轉 ×2」，或者「斷」。
- 稿紙最後一張換了，標記就消失。

### 成長：收工時四選二

| 選項 | 效果 |
|---|---|
| 邀請夥伴 | 同第三版 |
| 進修 | 一種結構升一級，以後每次打出這種結構 +40 籌碼、+4 倍率 |
| 改造素材 | 一張單一情緒的素材加上第二種情緒（相隔 2 至 4 格），自己造出層次、回響或張力的複合情緒 |

選完兩個再選一張新素材。新素材現在是三、四星。

### 目標

目標是 50,000、120,000 和 160,000，約為第三版的 2.5 倍，難度也提高了：

| 模擬玩家 | 第一晚 | 第二晚 | 第三晚 |
|---|---|---|---|
| 每筆隨機試 25 個次序 | 約 94% | 約 60% | 約 30% |
| 每筆試遍所有次序 | 通過 | 通過 | 通過 |

用每筆試 25 個次序的模擬玩家估計時，第三晚的目標是 180,000，後來降到 160,000。

## 歌：整套重寫（`music.js`）

照真實的製作習慣：

- **樂器**
  - FM 電鋼琴（Rhodes／DX 的做法：比例 1 的溫暖調變，加比例 14 的短促鐘聲）。
  - 撥弦算法（Karplus-Strong）的豎琴和結他。
  - 超級鋸齒波的弦樂墊、有濾波包絡的低音、FM 鐘。
  - 人聲有母音共振峰和氣聲。
- **鼓**
  - 有音高包絡和飽和的大鼓；小鼓的鼓身和響弦分開；city pop 加拍手。
  - 808 式的金屬鈸（六個不和諧的方波）。
  - 搖擺（lo-fi）、人手的微小誤差、輕擊的小鼓、段落之間的過門和鈸。
- **和聲**
  - 無根音的七和弦、九和弦排列（三音、五音、七音、九音），低音負責根音，聲部平順地走。
  - lo-fi 和 city pop 用大調的 maj9、m9、dom9；synthwave 用小調的 add9、maj7。
- **旋律**
  - 每晚一種節奏型，強拍落在有色彩的和弦音。
  - 整首歌共用一個動機；轉的地方升高，合落在主音。
- **編曲**：前奏兩小節 → 每一筆一段（每張素材一小節）→ 段落之間有過門和鈸 → 尾聲兩小節。
- **混音**
  - 電鋼琴和弦樂墊經過 chorus；立體聲乒乓回聲（附點八分音符）。
  - 有早期反射、能量歸一的殘響；synthwave 的小鼓有短房間殘響，低音和墊音跟大鼓「呼吸」。
  - lo-fi 加低通和飽和；最後是壓縮和限幅。
- **播放**
  - 整首歌按小節排程，提前 0.7 秒排下一小節。
  - 計分時只播兩拍的「草稿」，收工後才聽到完整的編曲。
- **檢查**：用 OfflineAudioContext 輸出三種風格，逐組量音量並看頻譜，再調整混音比例：
  - 低音原本太大聲，旋律太細聲，已經調整；
  - 殘響的脈衝原本沒有歸一，已經修正。

## 畫：整套重寫（`painter.js`）

- **光**
  - 窗、燈、招牌、月亮、火的光暈畫在獨立的光圖層，以 screen 疊上去，柔和而且會照亮周圍。
  - 水面有燈的長倒影。
- **遠近**：遠景混入天色，地平線有霧；建築分受光面和背光面；四邊有暗角。
- **細節**
  - 唐樓有冷氣機、晾衫竹、天台水缸、天線、天台招牌。
  - 人物是像素小人（站、坐、小孩、機械人、貓），有輪廓光；撐傘的人、燈柱、霓虹招牌、糖水檔、漁船。
  - 第二種情緒在水面或欄杆上加一盞那種顏色的燈，不再浮在半空。
- **會動（cinemagraph）**：雨、霓虹閃爍、倒影隨水波搖晃、波光流動、煙和蒸氣上升、星星閃、火星飄、船輕輕搖。
  - 作品頁和分享的重播頁都是會動的畫；作品集用靜態的截圖。

## 檔案

| 檔案 | 內容 |
|---|---|
| `engine.js` | 規則：起承轉合、複合情緒、題材、難題、提示次數、結構等級、收工的選項、作品碼 |
| `music.js` | 歌：混音台、和聲、旋律、樂器、鼓、按小節排程的整首歌、離線輸出（測試用） |
| `painter.js` | 畫：各圖層、光、建築、人物、會動的效果、逐格顯現 |
| `sfx.js`、`night.js`、`night.css`、`index.html` | 音效、畫面和演出、樣式、開發版頁面 |
| `build.js` | 打包：`node proto/night4/build.js [輸出檔] [--share 分享連結的前綴]`，背景音樂複製到輸出檔旁邊的 `audio/` |

原型不改 `game/`，舊模式和五輪模式完全不受影響。
