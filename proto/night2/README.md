# 創作之夜・起承轉合（原型第二版）

## 為甚麼做第二版

製作人試玩第一版之後說「好玩了很多，似回一個遊戲」，同時提出四點：
- 配色規則可以設計得更好；
- 要有真正創作的感覺：不只是顏色，還要有角色（和卡牌配合）；
- 作品不一定是畫，也可以是音樂（遊戲本來就設定了五種媒材）；
- 計分要像 Balatro 那樣，同時在過程中做出一件可以分享、有成就感的小作品。規則可以複雜一些，但要好玩。

第一版（`proto/night/`）保留不變，方便比較。

## 核心規則：起承轉合

素材按玩家點選的次序排成一行（稿紙）。相鄰兩張素材的情緒決定它們怎樣連接：

| 連接 | 條件 | 效果 |
|---|---|---|
| 承 | 有相同的情緒 | 倍率 +2 |
| 承 | 情緒在色輪上相鄰 | 倍率 +1 |
| 轉 | 情緒在色輪上相對 | 每一筆的第一個轉：倍率 ×2 |
| 斷 | 沒有關係 | 一行斷開，只計最長的一段 |
| 合 | 三張以上，最後一張和第一張是「承」的關係 | 倍率 ×2 |

另外三項加成：
- **起承轉合**：四張以上，先承、後轉，轉之後還有一張，最後合。倍率再 ×1.5。
- **獨白**：三張以上都帶着同一種情緒。倍率再 ×1.5。
- **編制**：三種媒材 +2，四種 +4，五種 +8；全部同一種媒材 +6。

倍率先加後乘，所以「先承、後轉、再合」得分最高。計分本身教玩家怎樣把作品寫好：轉折不要太早，結尾要回到開頭。

在 18 張的牌組裏，承（相同）、承（相鄰）、轉、斷四種連接各佔約 25%。大部分素材有兩種情緒，可以做兩邊的橋。

## 作品：同時是畫、歌和詩

每一筆計分的素材同時產生三樣東西：
- **畫**（`painter.js`）：整幅畫是一個大色輪。
  - 素材畫在它的情緒的位置；承沿着圈走，轉橫過中心，合回到起點。
  - 一晚四筆由外圈畫到內圈，疊成年輪。
- **歌**（`music.js`）：每張素材是一小節（兩拍）。
  - 情緒決定音色。
  - 媒材決定樂器：聲是旋律，身是鼓，數是琶音，影是和聲墊，紙是人聲。
  - 起承轉合決定和弦：起是主和弦，承順着走，轉是屬七和弦，合回到主和弦，所以結構越完整，歌就越好聽。
  - 計分時用快一點的拍子預演，作品頁才用原本的速度播放整首歌。
- **詩**：素材的名字依次成為詩句，每一筆是一節，並標出起、承、轉、合。紙素材的句子會唱出來。

收工後是作品頁，有畫、播放鍵（歌詞同步）、詩、署名和評審的評語。

分享：
- 「分享這件作品」產生一條連結，網址後面加 `#w2-…` 作品碼。作品碼只用英文字母、數字和連字號。
- 打開連結就會重播這件作品：同一個種子畫出同一幅畫，同一份和弦表唱出同一首歌。

## 角色：浮城的八位朋友做創作夥伴

夥伴取代了第一版的靈感物件。每位夥伴有計分效果，也在歌裏演奏，並在作品署名。

| 夥伴 | 計分效果 | 在歌裏 |
|---|---|---|
| 天台 DJ 小妹 | 每個承再 +2 | 鼓和低音 |
| 寫詩的何伯 | 合由 ×2 變成 ×3 | 朗誦 |
| 畫壁畫的阿 Ken | 轉由 ×2 變成 ×3 | 噴漆（畫上） |
| 改裝機械人的 Miu | 數素材計分兩次 | 電子琶音 |
| 唱粵劇的芳姐 | 起承轉合再 ×2 | 粵劇唱腔（在合） |
| 修船的老陳 | 每一筆第一個斷修補成承 | 木魚敲擊 |
| 寫歌的小雨 | 每張聲素材 +4 | 旋律 |
| 開糖水舖的 Mary 姐 | 每張人情 +2；獨白再 ×2 | 和音 |

主角有三種出身，素材和第一位夥伴各不相同：
- 前廣告公司文案，第一位夥伴是何伯；
- 街頭樂手，第一位夥伴是小雨；
- 失業動畫師，第一位夥伴是阿 Ken。

## 其他

- 三晚：社區小展（大調）、天台音樂會（小調）、外星評審（小調）。目標分數是 12,000、30,000 和 50,000。
- 校準用模擬玩家：每一筆隨機試若干個次序，挑最高分的一個。三晚的通過率如下：

  | 模擬玩家 | 第一晚 | 第二晚 | 第三晚 |
  |---|---|---|---|
  | 試 6 個次序（新手） | 98% | 62% | 26% |
  | 試 12 個次序 | 100% | 89% | 54% |
  | 試 25 個次序（熟手） | 100% | 97% | 76% |

- 評審的規則改成配合起承轉合。例如保育者「每個承再 +1」，灰人「KPI：沒有合的一筆不計分」。委託（評審想看的具名組合）保留。

## 檔案

| 檔案 | 內容 |
|---|---|
| `engine.js` | 規則（純邏輯，瀏覽器和 Node 共用）：連接、結構、計分步驟、夥伴、評審、委託、獎勵、作品碼 |
| `music.js` | 歌：調性、和弦進行、音色、樂器、整首歌的播放 |
| `painter.js` | 畫：色輪構圖、筆觸、重播 |
| `sfx.js` | 音效（和音樂共用同一個 AudioContext） |
| `night.js` | 畫面和演出、作品頁、分享和重播 |
| `night.css`、`index.html` | 樣式和開發版頁面（直接用瀏覽器開啟，讀 `../../game/js/` 的資料檔） |
| `build.js` | 打包成 Artifact 格式的單一檔案：`node proto/night2/build.js [輸出檔] [--share 分享連結的前綴]` |

原型不改 `game/`，舊模式和五輪模式完全不受影響。
