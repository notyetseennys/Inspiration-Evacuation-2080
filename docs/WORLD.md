# 世界觀與語氣聖經

> 製作人與 Claude 共同制定（2026-11-01）。**所有文字、美術、規則和數值都以這份文件為根據**；和其他文件衝突時，以這份為準。
> 外星種族按製作人的指定參照《星際之門》（第六節）。

---

## 一、一句話

2080 年，海水淹沒了沿岸的城市。外星文明像殖民時代的收藏家一樣來到地球，收集一個瀕臨滅絕的物種最後的靈感。你在內卷的浮城裡活下去，同時在極限中挑戰自己；活下去和登上巔峰之間是一條光譜，你停在哪裡，由你的信念決定。

## 二、遊戲要做到的

**越玩越深思，同時有爽感。**

- **深思**：每一局都令玩家多理解這個世界一點；選擇的代價看得見，後果會在之後出現；沒有正確答案。
- **爽感**：分數爆開、引擎「壞掉」、一筆過關，是每一晚的報酬。
- **兩者的關係**：爽感是光譜上「巔峰」那一端；深思來自代價。你登上巔峰的時候，看得見自己失去了甚麼。

一個要讓玩家慢慢發現的鏡像：外星人收集人類，玩家也在收集（物件、組合、作品、朋友的技法）。玩到某一局，玩家會意識到自己和外星人做着同一件事。

## 三、核心：生存與巔峰的光譜

| 生存 ← | → 巔峰 |
|---|---|
| 在內卷的世界活下去：錢、租、工作、人情 | 在極限的環境挑戰自己：火花、配色、作品、分數 |
| 代價：靈魂被三維世界牽絆，變重；靈感被日常消磨 | 代價：被外星人注意、被收藏、離開你在乎的人 |

- **不是二選一，是一條光譜**。每一天、每一次選擇，都把你推向某一端；最好的局通常兩端兼顧。
- 一局結束時你在光譜上的位置，連同靈魂的重量，決定你的結局，以及誰會來「收藏」你。
- **內卷從哪裡來**：外星人的名額有限，於是全城都在表演自己的靈感，爭取被選中（主視覺 KA-01 的「全城面試」）。外星人的存在本身就製造了內卷。

## 四、宇宙觀：柏拉圖空間

1. **柏拉圖空間（理型界）**：完美的形式所在。
2. **靈感**：理型投射到三維世界的過程。人創作時，把理型拉進三維世界；作品是投射留下的影子。
3. **靈魂**：本質在柏拉圖空間，借肉身在三維世界行走。
4. **靈魂的重量**：靈魂被三維世界牽絆的程度。為生存而作的妥協、執着和愧疚令靈魂變重；放下、付出和創作令靈魂變輕。重量是自然現象，不是道德審判，就像水往低處流。柏拉圖在《斐多篇》也說：被肉體牽絆的靈魂會變重，被拉回可見的世界。
5. **21 克**：靈魂離開三維世界的門檻。

遊戲裡的對應：

| 世界觀 | 遊戲 |
|---|---|
| 理型 | 配色（程式裡叫 FORM，柏拉圖的「理型」英文也是 Form） |
| 投影的清晰度 | 配色等級 |
| 投射的通道 | 火花 |
| 影子 | 作品 |
| 牽絆 | 靈魂重量 |

## 五、自然法則（道）

1. **能量守恆**：靈感不會憑空出現或消失。被收藏走的靈感，城市就失去了；城市越暗，留下的人越難有靈感。「靈感撤離」本身就是能量守恆。浮城的畫面已經會在朋友被帶走後熄燈。
2. **有得必有失**：每一樣得到的東西都有代價；每一次失去，也會留下一點東西。規則和數值要有這個對稱：沒有免費的加成，也沒有純粹的懲罰。
3. **陰陽**：相反的力量互相成就，例如色輪上的互補色，以及生存與巔峰。
4. **物極必反**：走到極端就會反轉。
   - 靈魂太重，光束拉不動你；靈魂太輕，你變成外星人的完美員工；
   - 火花太旺會燒盡；
   - 分數太高，會引來你不想被注意的外星人。
5. **法則要在規則裡看得見**，不只寫在文字裡。新的規則或數值，都要先問：它的代價是甚麼？它的極端會怎樣反轉？

## 六、外星人

### 1. 為甚麼來地球

像殖民時代的收藏家：帶着獵奇的心態，把一個瀕臨滅絕的物種最後的文化收進自己的收藏。對他們來說，「撤離」同時是保育、掠奪和展覽。

### 2. 很多種族，互相衝突

- 對人類的態度是一條光譜：研究、冷漠、喜歡、不喜歡。
- 每個種族收藏的東西不同、方法不同、對待收藏品的方式不同；他們爭奪同一件收藏品，看不起對方的收藏方法，也簽條約、也走私。
- **參照《星際之門》**（製作人指定）：每個種族參照劇中一個種族「對人類的態度和關係」。名字、外形和設定全部原創：一來避免版權問題，二來我們的外星人都是「收藏家」，動機和劇中不同。

### 3. 種族

| 種族 | 參照 | 態度 | 為甚麼收藏、收藏甚麼 | 被選中之後 | 腔調 |
|---|---|---|---|---|---|
| **灰人**（星際人才發展局） | Asgard：靠複製延續、正在衰亡的高等種族，長期研究人類 | 冷漠（研究） | 複製了太多代，再也接觸不到柏拉圖空間，自己不再有靈感，只能「招聘」人類的靈感。收藏有用的人才：建檔、評分、KPI | 員工（星際特工、完美員工）、存檔（人才庫）、退貨（被遣返） | 人事部術語：「表現符合預期」 |
| **鏡神族** | Goa'uld：冒充神明、奴役人類 | 不喜歡 | 沒有固定的形體，在人面前化成對方崇拜的樣子：神明、偶像、名人、品牌。以崇拜為食，在浮城經營「被提」信仰：「探射燈就是神的呼召」 | 成為偶像：被千萬人崇拜，自己卻空了 | 經文和廣告文案混在一起 |
| **收割者** | Wraith：把人類當作牧場 | 不喜歡 | 靈感是糧食。苦難令靈感豐收，所以他們暗中令浮城的災難維持下去。只要靈感，不要人 | 被抽乾，變成灰（「灰化」結局） | 農業報告：「本季收成」 |
| **保育者** | Aschen：以施惠為名的慢性滅絕 | 喜歡（家長式） | 把人類當作瀕危物種保護，在自己的星球建「人類保護區」 | 保護區居民：安全、富足、有醫療，但永遠不能離開。保護區裡再沒有人創作，他們不知道這正是滅絕 | 自然紀錄片的旁白 |
| **先選者** | Tollan：被移居的人類，自視高人一等，不肯幫助落後的種族 | 冷漠（輕蔑） | 不收藏。他們是幾個世紀前被收藏的人類的後代，如今是先進文明，認為地球人「要靠自己的自然發展」 | 加入他們，學會看不起留下的人。**被選中的人最後變成看不起地球的人**，這是最深的一面鏡子 | 有禮貌的輕蔑 |
| **逃兵網絡** | Tok'ra：從敵陣叛變、和人類結盟的反抗者 | 喜歡 | 由各個種族的叛逃者組成，幫人類逃過收藏；人數少，一直被追捕 | 不是被收藏，是加入反抗 | 暗號 |
| **升維者** | Ancients：升上更高層次、不干預 | 冷漠（不干預） | 已經升入柏拉圖空間，成為純粹的理型。只看，從不出手，這是他們的規矩 | 他們不選人。但一個夠輕、夠亮的靈魂，可以不靠飛碟，自己升維：真正的「撤離」（隱藏結局） | 幾何和沉默 |
| **淨化派** | Ori：要求信仰、燒毀異端的升維者 | 不喜歡 | 升維者的分支，相信只有一種「正確的理型」，其他靈感都是異端和噪音。不收藏，只清除 | 被淨化：只准創作「正確」的作品 | 衛生部門的通告和教條 |

遊戲裡已經有的：灰人逃兵（逃兵網絡）、章魚星人詩人、蘑菇星交換生；「人類樣本檔案」是灰人的表格；內容農場裡有「@被提預備」的帳號（鏡神族）；阿星的訊息「第 7 區本季超額完成靈感收割指標」（收割者）；「灰化」和「平凡人」結局；19 位評審之後按種族分派。例如「純度檢驗官」「類比原教旨官」「白盒苦行僧」屬於淨化派，「深空觀測員」屬於升維者。

### 4. 衝突與條約

- **星際條約把地球的浮城劃成不同的區**：招聘區（灰人）、保護區（保育者）、收成區（收割者）、朝聖區（鏡神族）、觀光區（章魚星人）、清除區（淨化派）。每座浮城屬於哪一區，決定了那裡的事件和人生（第七節）。第一座浮城是灰人的招聘區「第 7 區」。
- 灰人和保育者爭奪同一批人類：一方說是「招聘」，一方說是「綁架」。
- **灰人和收割者暗中勾結**：發展局的「靈感收割指標」，其實是收割者的訂單。這是「揭穿真相」結局的根據。
- 鏡神族和逃兵網絡互相追殺；淨化派燒毀所有收藏家的收藏；先選者不幫任何一方；升維者看着一切，從不出手。

### 5. 被選中之後

有很多可能，取決於哪個種族選中你、你在光譜上的位置和你的靈魂重量。每一個都有得有失：展品被保存，但失去自由；員工有地位，但失去人性；保護區安全，但永遠不能回家；偶像被崇拜，但自己空了；升維得到一切，但要放下一切。

## 七、世界：很多座浮城

- 2080 年，海平面上升、極端天氣和洋流崩潰，令沿岸城市變成「浮城」。根據是氣候推算和近年的極端天氣，也參考了電影《明日之後》。
- **每一天都可能被浸沒**（製作人 2026-11-11）：水位是日常的壓力，不是背景。
  - 水淹到家的後果由輕到重：預警 → 受傷 → 被水帶走一樣東西 → 失去住所。
  - 樓層越高越貴；錢不夠搬的人，只能看着水上來。
  - 每個角色的故事、事件、阿星的訊息、卡的來歷，都要讓人感覺到水。
- **寒潮**：暖化令洋流停頓，天氣在酷熱和急凍之間擺盪。寒潮季水面結冰，水位暫時不升；季節一過就融冰，水位一次過上升。
- 制度的說法永遠輕描淡寫：氣象局改名「水位局」；淹水叫「輕微滲漏」；融冰叫「季節性補償」。
- **浮城有很多座，各有特色**。每座有自己的災害、文化、行業、階級結構、人物和事件；外星人在每座城收集的東西也不同。
- 現在的浮城是第一座：颱風、粵劇、糖水、唐樓、天橋、天台。之後的城市在第二十期起加入。
- 每座新城市都要定義這些項目：

| 項目 | 例子（第一座浮城） |
|---|---|
| 災害 | 風暴季、熱浪季、酸雨季、寒潮季；水位每晚上升，寒潮季結冰、之後融冰 |
| 文化 | 粵劇、糖水、唐樓、天台派對 |
| 經濟 | AI 標註、外送潛水、黑市義體 |
| 貨幣 | 浮城元，與星際信用點掛鈎；聯繫匯率靠「人才出口」維持 |
| 難度 | 1（比較輕鬆）：物價穩定、找得到散工；代價是這座城市最主要的出口是人 |
| 階級 | 越高越乾、越富有；天空區浮在上空 |
| 外星人在這裡收集甚麼 | 正在消失的地方藝術 |
| 八位朋友 | 阿 Ken、小妹、何伯、Miu、芳姐、老陳、小雨、Mary 姐 |

- **每座浮城的經濟不同，有難易之分**：由 2026 年的世界推演到 2080 年（通脹、海平面上升、AI 和平台、外星人、貨幣分化）。有的城市掛鈎（比較輕鬆），有的惡性通脹（「委內瑞拉化」），有的只發企業代幣。故事線的報酬和掙扎跟所在的城市有關。詳見 `docs/ECONOMY.md`。

## 八、批判與選擇

- **批判整個世界**：外星人、企業、有錢人、窮人、AI、玩家自己，沒有一個是純潔的，也沒有單一的壞人。
- **遊戲不判斷對錯**：沒有「正確」的結局；每個結局都寫明得到甚麼、失去甚麼。
- **希望**，在於看清自己身處的環境，有足夠的資訊，按自己的價值觀行動。設計上：
  - 代價在選擇之前看得見（卡上寫明錢、火花、靈魂的變化；朋友被收藏之前有預告）；
  - 世界的真相一層一層揭開：外星種族、阿星、柏拉圖空間。每一局多知道一點，理解本身就是進度。

## 九、黑色幽默

- **甚麼都可以笑**：死亡、外星人、企業、窮人、有錢人、宗教、藝術，還有玩家自己。
- **只笑 2080 年的世界**：不寫真實的人、品牌、地標、時事和現在的政治；從現在推演到 2080 年。
- **寫法**：冷面，用平淡的語氣講慘事，精華在最後一句（設計大綱）。
- **畫面**：冷面；只有企業和有錢人有霓虹色；暖光留給真正的人情（見 `docs/art-prompts/`）。

## 十、語氣

- 遊戲文字用繁體中文書面語。
- **不說教、不審判**：遊戲描述後果，不判斷對錯。現有的「虧心」「良知」等字眼要檢討。
- **每個外星種族有自己的腔調**：見第六節的表。
- **朋友**：真誠，各有口癖（照現有的對白）。
