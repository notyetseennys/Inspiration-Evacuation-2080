# 第十六至二十期：工單清單

> 這些是預定的工單。**第十五期合併之後，Claude 才會把每一期寫成正式工單**（連同總規格、測試和驗收數字），因為細節取決於第十五期的實作和模擬結果。設計依據見 `docs/REFORM_PLAN.md`。

## 第十六期：引擎（越滾越強）

目標：滾雪球倍數（第 15 晚 ÷ 第 1 晚）由約 30 倍升到 100 倍以上；至少 8 種打法可以贏。

| 預定工單 | 內容 |
|---|---|
| WO-16-01 物件資料格式 | 物件新增 `grow`（成長型）、`rule`（改寫規則）、`econ`（經濟）、`soulFx`（靈魂）四類效果的標準寫法和計分鉤子 |
| WO-16-02 成長型物件 | 約 30 件：每次某事發生，永久累積倍率或籌碼（例如「舊城日記」） |
| WO-16-03 改寫規則的物件 | 約 15 件：「對立統一」「漸層筆」「眾聲喧嘩」「一意孤行」「亂塗」等，配色判定讀取這些規則 |
| WO-16-04 對立物件 | 五對相反情緒各一件傳說物件 |
| WO-16-05 牌組雕塑 | 市集服務加入染色、剪裁、拼貼；服務改為每次兩項 |
| WO-16-06 色輪預覽 | 滑過或長按手牌，色輪用虛線預覽加入後的形狀和倍率；配色表永遠顯示 |
| WO-16-07 配色平衡 | 四色略降、單色可行、矛盾成為隱藏大獎；主色規則 |
| WO-16-08 工作室升級 | 家具改為一局內的永久升級（手牌 +1、物件欄 +1、改稿 +1 等），在遺物環節出現 |
| WO-16-09 AI 模仿改為評審規則 | 常駐的 AI 模仿取消，只作為外星評審規則 |
| WO-16-10 角色適配 | 二十個角色的招牌能力在五輪模式全部有意義（與身體、日子有關的改寫） |
| WO-16-11 模擬與校準 | 八種打法的機械人；驗收：各 20% 以上勝率、沒有配色超過 35% |
| WO-16-12 移除舊模式 | 刪除速寫、通宵、一天三時段等舊流程（經典模式保留與否由製作人決定） |

## 第十七期：作品牆

| 預定工單 | 內容 |
|---|---|
| WO-17-01 作品的資料 | 作品有名氣、價值；每晚最好的一筆成為候選作品 |
| WO-17-02 掛、賣、捐 | 三個選擇與規則；牆的格數 |
| WO-17-03 作品的計分 | 共同情緒 +名氣倍率、同配色 ×1.5；名氣成長 |
| WO-17-04 作品牆介面 | 牆上的畫、名氣、賣價；結束面板的選擇 |
| WO-17-05 沉入舊城 | 每局最好的作品跨局保存，下一局潛水時有機會撈回 |
| WO-17-06 模擬與校準 | 收藏家策略；驗收：作品牆貢獻 ×1.5–3、每局賣出 3–6 幅 |
