## 目標

五輪模式的白天面板頂部，有一幅會動的浮城夜景。玩家不用看數字，也知道今晚的水有多高、天氣怎樣、是不是寒潮：水位高，水就淹上遠處的樓和碼頭；寒潮來，水面結冰、下雪。

畫面的做法已經在原型驗證過。**先讀 `proto/night5/painter.js`**（387 行），把其中「場景」的部分搬過來。原型可以在瀏覽器看：製作人會提供連結。

## 已經準備好的東西（不用做）

- `game/art/`：154 張 WebP 素材和 143 張光暈圖（共 4.2 MB）。**不內嵌到單檔版。**
- `game/js/data-art.js`：`IE.DATA.ART`。
  - `a[名稱] = { w, h, fl?, g? }`：寬、高；`fl: 1` 是浮在半空的素材（沒有倒影）；`g: 1` 表示有光暈圖 `<名稱>.glow.webp`。
  - `sky[名稱] = [r, g, b]`：那張天空的平均色，用來統一色調。
  - `W: 960, H: 600, horizon: 340`。
- 素材名稱：`np-sky-<情緒>-<1|2>`（20 張）、`np-far-<drowned|industry|neon|old|ruin|sky>`、`np-stage-pier-<1|2|3>`、`np-mid-*`（30 張）、`np-front-*`（12 張）。這張工單不用 `np-focal-*`、`np-duo-*`、`np-mate-*`。

## 規格

### 1. `IE.NightScene`（新檔 `nightscene.js`，在 `ui.js` 之前載入）

| 函數 | 行為 |
|---|---|
| `plan(s)` | **純函數**，不碰 DOM。由局面算出要畫甚麼，回傳 `{ seed, sky, far: [兩個名稱], mids: [三個名稱], pier, front, flood, cold, rain, stage }`。同一個局面永遠回傳相同的結果 |
| `mount(canvas)` | 開始在這個畫布上畫；回傳 `{ set(plan), stop() }`。`set` 換場景時用 0.6 秒淡入，不要閃 |
| `base()` | 回傳素材的路徑：`(window.IE_ART_BASE || '') + 'art/'` |

`plan(s)` 的規則：

- `seed`＝`s.seed` 和 `s.round` 組成的整數（同一輪的三晚是同一個地方，換輪才換景）。
- `stage`＝`IE.Flood.stage(s)`。`flood` 按階段：`dry` 0、`warn` 0.35、`light` 0.6、`medium` 0.8、`heavy` 1。
- `cold`＝`s.season === 'cold'`。
- `sky`：今晚的天氣有 `tag.t` 就用 `np-sky-<tag.t>-<n>`；沒有就按季節用預設的情緒（風暴季 `water`、酸雨季 `machine`、其餘 `neon`、寒潮季 `memory`）。`n`：天氣的 `vis` 是 `storm` 或 `typhoon` 用 2，否則用 1。
- `rain`：天氣的 `vis` 是 `drizzle`、`storm`、`typhoon` 時為 `true`；`cold` 時一律 `false`（改為下雪）。
- `far`、`mids`、`pier`、`front`：用 `seed` 從清單裏抽，不重複。`front` 不可以抽到 `np-front-frame-gold`。`stage` 是 `medium` 或 `heavy` 時，`far` 的第一個固定用 `np-far-drowned`。
- 回傳的每一個名稱都必須在 `IE.DATA.ART.a` 裏。

### 2. 怎樣畫（照 `painter.js`）

由遠到近：天空 → 兩排遠景 → 水面（天空的倒影、水波）→ 三件中景和倒影 → 碼頭 → 前景框。然後：

- **光暈**：有 `g: 1` 的素材，把光暈圖放大四倍，用 `screen` 疊上去；中景的光暈在水面拉長成倒影。
- **水位**：`flood` 越高，水面那條線越高（`painter.js` 的做法：最多升 36 像素），蓋過遠景和中景的底部；`flood > 0.55` 時碼頭底部也浸在水裏。
- **寒潮**：水面不動，蓋一層冰和裂紋；下雪；整體偏冷色。
- **雨**：`rain` 為 `true` 時下雨。
- **動態**：天空慢慢橫移、中景輕微浮動（浮空的幅度大些）、水面閃光、霓虹呼吸；`np-sky-(anger|rebel)-2` 偶然有閃電。
- 中景和前景按 `sky` 的平均色統一色調。

**重要：不可以用 `getImageData`。** 單檔版用 `file://` 開啟，讀畫布像素會出錯。原型用 `getImageData` 找發光像素的那一段，改為直接載入光暈圖；天空的平均色用 `IE.DATA.ART.sky`。

### 3. 介面

- 白天面板最上面加 `<div class="rd-vista" data-stage="<階段>" data-cold="<0|1>"><canvas width="960" height="600"></canvas></div>`。
- `.rd-vista` 的比例是 8:3，畫布用 `object-fit: cover; object-position: 50% 72%`（看到的是地平線、水面和碼頭）。圓角和邊框跟其他面板一致。
- 白天面板重新渲染時**不要重建畫布**：畫布只掛載一次，之後呼叫 `set(plan(s))`。
- 只在五輪模式出現。舊模式不變。
- 水位條 `.rd-water`（WO-16-06）保留；夜景不取代數字。

### 4. 載入、失敗和效能

- 開發版（`game/index.html`）的路徑是 `art/`；單檔版在 `tools/build.js` 寫 `IE_AUDIO_BASE` 的同一處加 `window.IE_ART_BASE = "../game/";`。
- **任何一張圖載入失敗，或者 `IE.DATA.ART` 不存在：給 `.rd-vista` 加 `is-off`（`display: none`），遊戲照常運作，不可以有 JS 錯誤。** 單獨把 `dist/` 的檔案拿走也要可以玩。
- 用到的圖才載入（一幅景約 10 張圖和光暈圖）。
- 每秒最多 30 格；頁面不可見（`document.hidden`）或者 `.rd-vista` 不在畫面內就停。
- `prefers-reduced-motion: reduce`：只畫一格靜止的畫，沒有雨、雪、閃電和浮動。
- `dist/inspiration-evacuation-2080.html` 必須仍然小於 4 MB，而且裏面沒有任何 `np-` 圖檔的資料。
