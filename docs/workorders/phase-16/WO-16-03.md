# WO-16-03：小遊戲的抉擇（標註、送貨、診所）

| 項目 | 內容 |
|---|---|
| 期數 | 第十六期甲段（總規格 §4） |
| 依賴 | WO-16-02（`game/js/data-stance.js` 已提供） |
| 規模 | 大（約 500 行） |
| 分支 | `gemini/wo-16-03-stance-a` |
| 可以改的檔案 | `game/js/micro-label.js`、`game/js/micro-delivery.js`、`game/js/micro-clinic.js`、`game/js/micro.js`（共用的部分）、`game/js/jobs2.js`（套用立場）、`game/js/auto.js`、`game/css/polish.css`、新檔 `tools/tests/stance.test.js`、`tools/smoke-rounds.js`（只加新的檢查）、`docs/shots/`、`dist/` |
| 不可以改 | `data-stance.js` 的文字和卡（有問題在 PR 提出）；其他小遊戲 |

## 目標

三個小遊戲各加一個兩難，玩家用玩法本身回答；回答決定收入、靈魂和得到的卡。同時按總規格 §4.4 的五點把這三個小遊戲改得更好玩。

## 規格

### 1. 共用（`micro.js`、`jobs2.js`）

- 小遊戲的結果加上 `res.stance`（`'comply'`、`'resist'`、`'care'` 或 `null`）。
- `jobs2.js` 套用結果時（只在五輪模式）：
  - 收入乘 `ECON16.stancePay[stance]`；
  - `comply`：`sin +1`；`care`：`atone +1`；
  - 得到的卡改為 `D.STANCE[micro][stance]` 的卡（星級再按總規格 §3.3 調整），`origin` 是 `{ kind: 'work', x: 小遊戲的名稱 }`；
  - 報告加一行 `D.STANCE[micro].lines[stance]`。
- `IE.Auto`：`stance` 一律是 `'comply'`，報告的那一行用 `D.STANCE_TEXT.auto`。
- 結算畫面：`.mg-stance.s-<stance>`，顯示 `D.STANCE_TEXT[stance]`、那一句話和得到的卡。

### 2. 三個小遊戲的兩難

兩難出現時**不暫停、不彈視窗**；出現的時間在整個小遊戲的 40% 至 70% 之間（用局內的亂數）。

| 小遊戲 | 出現 | comply | resist | care |
|---|---|---|---|---|
| `label` | 連續 4 張抗議的照片；畫面上方的 KPI 提示換成「本批建議標籤：暴力」 | 4 張都標「暴力」 | 4 張都標「集會」 | 至少 1 張按「跳過」（新的按鈕，只在這 4 張出現；其中一張的人是一位還在浮城的朋友） |
| `delivery` | 路上出現一個倒下的人（像素小人，旁邊有求助的標記） | 繞過去，準時送到 | 把貨丟進海裏（把貨拖到水面） | 停在那個人旁邊 3 秒 |
| `clinic` | 藥的數量變成病人的一半；每個病人頭上多了保險等級 | 只派給金、銀級 | 按排隊的次序派 | 把自己的那一格藥（畫面角落，新的）也派出去 |

- 混合的回答按多數決定；分不出就是 `comply`。
- 每次的對象不同：名字和樣子從 `D.NPCS`（還在浮城的）和路人表抽。

### 3. 更好玩（總規格 §4.4）

每個小遊戲都要在 PR 逐點說明怎樣做到：十秒學會、有冒險的選擇、抉擇是玩法的一部分、結果是一句話、每次不同。冒險的選擇建議：

- `label`：連續標對有連擊倍率，標錯一張歸零；
- `delivery`：可以走近路穿過管制區，快一倍，但被無人機看見就扣錢；
- `clinic`：可以一次處理兩個病人，手忙腳亂時容易派錯。
