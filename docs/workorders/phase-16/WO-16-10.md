## 目標

五輪模式的創作之夜：玩家每下一筆，畫就多一層；卡面是真的圖；整個畫面在手機一屏之內。

**先讀 `proto/night5/night.js`（介面）和 `proto/night5/painter.js`（畫）**，並且在瀏覽器玩一次原型（製作人會提供連結）。這一張的工作是把那個畫面搬入主遊戲，用主遊戲的規則和資料。

## 規格

### 1. 版面（手機 390×844 一屏，不用捲動）

由上到下：

| 區域 | class | 內容 |
|---|---|---|
| 畫 | `.dk-canvas` | 16:10 的畫布（內部 960×600） |
| 分數 | `.dk-score` | 今晚的分數／目標、進度條、第幾筆（四點）、達標印、評審的規則一行 |
| 稿紙 | `.dk-row` | 選了的素材按次序排成一行；相鄰兩張之間有 `.dk-link.k-<same|near|zhuan|duan>`，寫「承」「轉」「斷」；首尾是合時有 `.dk-he` |
| 預覽 | `.dk-preview` | 結構的名稱、籌碼 × 倍率（不顯示總分，留懸念） |
| 手牌 | `.dk-hand` | 卡是 `.dk-card[data-uid]`，卡面是圖，下面是名字、情緒的標籤、星級 |
| 按鈕 | `.dk-actions` | 改稿、下筆；物件、牌庫、圖鑑收在一個「⋯」選單 |

- 桌面版（≥ 900px）：畫在左，其餘在右，同樣不用捲動（1280×800）。
- 色輪、配色表、媒材統計不顯示。物件和流派收在「⋯」選單，計分時觸發的物件在畫的旁邊閃一下。
- 所有可以按的東西不小於 44×44px。

### 2. 畫（總規格 §10.5）

- `IE.NightScene.paint(canvas)` 回傳 `{ stroke(n, info), finish(), snapshot() }`。`info` 來自 `scorePlay` 的結果：`roles`、計分的素材、主調。
- 四筆對應四層；純函數 `IE.NightScene.strokePlan(s, n, res)` 決定這一筆畫甚麼，回傳素材名稱的清單（可以測試）。
- 素材出現時由上方落下並有火花；「轉」的那一格放大、有聚光；「合」時全畫的燈變亮。
- 水位、寒潮、雨照今晚的局面（和白天的夜景一致）。
- 每張圖只在用到時載入；載入失敗就略過那一層，不可以出錯。

### 3. 計分的演出

逐步照 `steps`：素材逐張亮起（卡飛到畫上），連接逐個亮起（「承 +2」「轉 ×2」），複合情緒顯示名字（例如「雨後・交融」），最後倍率和籌碼相乘。速度沿用現在的「速度 ×1／×2／跳過」。

### 4. 收工的作品頁

`.dk-work`：整幅畫、作品名（沿用 `workName`）、每一筆的素材名排成的幾行、今晚的分數／目標和超額的級數、按鈕「去市集」。畫存入作品集：`s.gallery` 的那一項加 `paint: { seed, strokes: [...] }`，作品集用同一個畫布重畫（不存圖片）。

### 5. 沒有美術包時

`IE.DATA.ART` 不存在或者圖全部載入失敗：`.dk-canvas` 改為顯示舊的色塊作品（`IE.Artwork.svg`），卡面顯示情緒的顏色，其餘照常。

## 驗收條件

1. `node tools/test.js` 全部通過，包括 `tools/tests/deskpaint.test.js`：
   - `創作桌畫面：四筆分別是天空和遠景、中景、碼頭、前景`
   - `創作桌畫面：有轉的第一筆用第二張天空`
   - `創作桌畫面：中景和碼頭用起、轉、合三張素材的圖`
   - `創作桌畫面：三筆完整的起承轉合用金框`
   - `創作桌畫面：strokePlan 的每個名稱都在清單裏`
   - `創作桌畫面：同一局同一晚的畫可以由記錄重畫`
2. `node tools/sim.js 20` 和 `node tools/sim-rounds.js 200` 的輸出和合併前**完全相同**（這一張不改規則）。
3. `node tools/smoke.js`、`node tools/smoke-rounds.js` 通過；`smoke-rounds.js` 加入：
   - 五輪模式的創作之夜有 `.dk-canvas canvas`、`.dk-row`、`.dk-hand .dk-card`；沒有色輪；
   - 手機 390×844 和桌面 1280×800：`#ctable` 的 `scrollHeight` 不大於視窗高度，沒有橫向捲動；
   - 選三張卡之後 `.dk-row` 有兩個 `.dk-link`；
   - 下四筆之後出現 `.dk-work`；
   - `IE.DATA.ART = null` 時整晚可以玩完，沒有 JS 錯誤；
   - `craft.js` 和 `nightscene.js` 沒有 `getImageData`。
4. 截圖（手機和桌面，用 `dist/` 的單檔版以 `file://` 開啟）：四筆各一張、計分途中、作品頁、作品集，存在 `docs/shots/wo-16-10-*.png`。
5. `node tools/build.js` 之後提交 `dist/`，小於 4 MB。
