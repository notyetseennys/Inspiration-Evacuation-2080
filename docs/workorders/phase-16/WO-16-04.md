# WO-16-04：卡背、回憶和差事的介面

| 項目 | 內容 |
|---|---|
| 期數 | 第十六期甲段（總規格 §6） |
| 依賴 | WO-16-01、WO-16-02 |
| 規模 | 中（約 350 行） |
| 分支 | `gemini/wo-16-04-card-ui` |
| 可以改的檔案 | `game/js/ui.js`、`game/js/main.js`、`game/css/polish.css`、`tools/smoke-rounds.js`、`docs/shots/`、`dist/` |
| 不可以改 | 邏輯檔案和資料檔 |

## 目標

玩家看得見每張卡的來歷，自己決定放下哪一張，並且知道今天有沒有工作的差事。

## 規格

照總規格 §6 的表實作全部元件，class 名稱和 `data-do` 要完全相同。補充：

1. **卡背**：在素材庫、創作桌的手牌、市集和放下一張卡的視窗，卡上都有 `[data-do="cardback"]`（長按或右上角的小按鈕，不可以和「選卡」的點擊衝突）。卡背像一張寫了字的紙：來歷是手寫感的一句話，下面是作品的名字。
2. **放下一張卡**：`s.over` 為 `true` 時，白天和市集結束之前一定要處理。視窗不可以關閉；選了之後有一個「放進盒子」的短動畫（減少動態效果時直接消失），然後顯示「你把『X』放進了回憶。」
3. **回憶**：灰色的卡，按得到的次序排；可以看卡背，不可以拿回來。
4. **差事**：生活卡上的 `.dc-gig` 要比其他標記顯眼（這是一天裏最重要的資訊）；剩 1 天時變成警告色。沒有差事的日子，白天面板顯示 `.rd-nogig`。
5. **過期**：`expireGigs` 回傳的差事，在白天面板最上面顯示 `D.GIG_TEXT.expired`，按一下消失。
6. 做減法：不要加新的常駐欄位；來歷只在卡背顯示。
7. 來歷在 `card.from`（不是 `card.origin`，那是出國素材的地區）。
8. `IE.Rounds.choose()` 裏有一段保險：已經選了生活卡而素材庫仍然超過上限時，會自動放下一張。做好「放下一張卡」的視窗之後，正常流程要先讓玩家選，不可以依賴這段保險。

## 驗收條件

1. `node tools/test.js`、`node tools/smoke.js` 通過。
2. `node tools/smoke-rounds.js` 通過，並加入這些檢查：
   - 開局的卡可以打開 `.card-back`，裏面有 `D.CARD_TEXT.backHead` 和 `D.ORIGIN.start` 的文字；
   - 把素材庫塞到超過上限之後，出現 `.rd-over`，按 `[data-do="putdown"]` 之後視窗消失，`s.memory.length` 是 1；
   - `[data-do="memory"]` 打開 `.rd-memory`，裏面有剛才那張卡；
   - 第一輪第一天的生活卡有 `.dc-gig`；用掉之後，下一天有 `.rd-nogig`；
   - 手機 390px 沒有橫向捲動；新的按鈕至少 44px 高。
3. 截圖（桌面和手機）：卡背、放下一張卡、回憶、有差事的白天、沒有差事的白天，存在 `docs/shots/wo-16-04-*.png`。
4. `node tools/sim.js 20` 的輸出和合併前**完全相同**；`node tools/build.js` 之後提交 `dist/`。
