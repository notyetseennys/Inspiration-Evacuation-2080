## 目標

五輪模式的創作之夜改用起承轉合：素材按選的次序排成一行，次序決定分數。這一張只做規則、機械人和模擬器；介面只要可以玩，好看留給 WO-16-10。

## 先讀

1. 總規格 §10。
2. `game/js/desk.js`：規則核心已經寫好，**直接呼叫，不要重寫**。
3. `proto/night5/engine.js` 的 `score`（第 382 行起）：原型怎樣逐步套用。主遊戲的做法見下面 §1。

## 規格

### 1. `IE.Create.scorePlay`（只在 `IE.Rounds.on(s)` 時走新的路）

照總規格 §10.3 的五步。細節：

- `uids` 的次序就是玩家選的次序，不可以排序。
- `repair`：熟絡度滿的朋友的數目，上限 1。
- 回傳值保留原有的欄位，令其他程式不用改：`form`（結構 id）、`level`、`scoring`（`A.run` 的 uid）、`chips`、`mult`、`total`、`raw`、`steps`、`recipes`、`relief`、`schools`。另外加：`links`（`A.links`）、`roles`、`he`、`noise`（沒有計分的 uid）、`subject`、`s`、`e`。
- `steps` 新的種類照 `IE.Desk.structSteps`：`link`、`compound`、`media`、`subject`、`he`、`title`；每一步照現在的做法加上 `C`、`M`。
- 評審的規則（`IE.Stages.scoring`）繼續生效；`SR.mult(form, …)` 收到的是結構 id。
- `preview`、`suggest`、`chase`、`bestPlay` 在五輪模式也要用新規則。`bestPlay` 要試不同的次序：五張以內試遍所有排列，回傳分數最高的次序。

### 2. 配色 id 換成結構 id

- 新檔 `data-desk.js` 加 `D.DESK_REMAP`：五輪模式裏，每一處用到配色 id 的資料怎樣對應。對照表用 `D.DESK.formMap`。
- 用 `grep` 找齊所有用到 `'mono'`、`'adj'`、`'triad'`、`'split'`、`'comp'`、`'tetrad'`、`'full'`、`'mix'`、`'paradox'` 的地方（`data-craft.js`、`data-schools.js`、`data-world.js`、`jobs2.js`、`rounds.js`、`stages.js`），在 PR 列一張表：檔案、行、原本的意思、五輪模式的對應。
- `D.FORMS` 在五輪模式由九種結構取代：技法課、圖鑑、`s.forms`、`s.style` 的鍵都是結構 id。名稱和說明用 `IE.Desk.STRUCT`。
- 舊模式讀到的資料必須和現在完全相同。

### 3. 一晚的流程（總規格 §10.4）

- 分數到了目標不結束：`session.passed = true`，之後每一筆 `session.encore += 1`，火花 +0.1。
- 四筆用完才可以收工；素材庫和手牌都沒有可以下的素材時也可以收工。
- 超額三級：`D.ECON16.over = [{ x: 2, spark: 0.2 }, { x: 5, spark: 0.4, ticket: 1 }, { x: 10, spark: 0.6, ticket: 1 }]`，只給最高的一級；取代現在的單一級。

### 4. 平衡的素材（總規格 §10.6）

把 `proto/night5/deck.js` 的 75 張素材搬到 `data-desk.js`，id 由 `n5_*` 改為 `dk_*`，名字、情緒、媒材、星級照原型。五輪模式的開局補充素材、素材包、市集和小遊戲的獎勵從「原有素材＋`dk_*`」抽。舊模式抽不到 `dk_*`。

### 5. 介面的最小改動（`craft.js`）

- 手牌被選的卡顯示次序的數字（1、2、3……）；再按一次取消。
- 色輪在五輪模式不顯示；原來顯示配色名稱的地方顯示結構的名稱。
- 計分的演出遇到新的 `steps` 種類不可以出錯：`link` 顯示「承 +2」「轉 ×2」，其餘顯示名稱和數值。
- 教學（創作互動導覽）在五輪模式暫時關閉（WO-16-11 重做）。

### 6. 機械人和模擬器

- `IE.Auto` 和 `sim-rounds.js` 的機械人用新的 `bestPlay`。
- 新增兩種策略：`novice`（每筆從手牌隨機抽三組、每組一個隨機次序，取最高）、`expert`（`bestPlay` 加上每晚保留最好的結構到最後一筆）。
- 輸出多兩行：結構分佈（九種的百分比）；每晚「總分 ÷ 目標」的中位數（第 1、3、6、9、12、15 晚）。
