## 做了甚麼

1. **資料**：`D.SEASONS.cold`（和總規格 §8.1 逐字相同）、`D.SEASON_ORDER16`、三種天氣、`D.FLOOD_TEXT.thaw`。
2. **季節的次序**：`IE.Rounds.advance` 換季時，有寒潮系統就用 `D.SEASON_ORDER16`。開局的季節不變。列舉 `D.SEASONS` 的五處（開局頁的季節按鈕、開局頁預設的季節、每日挑戰、每週挑戰、兩個模擬器）全部改用 `D.SEASON_ORDER`，舊模式永遠不會抽到寒潮季（次序和以前相同，所以結果不變）。
3. **結冰**：寒潮季 `water` 是 0，水位不升；`IE.Flood.tick` 在寒潮季不增加 `floodRun`（已經淹了的維持原來的階段），「輕」的損失照常。
4. **不能潛水**：寒潮季的生活卡沒有 `dive`；潛水的差事因此不會出現在當天的選擇，已經有的照常過期。
5. **融冰**：由寒潮季換到下一季的那一晚，`s.water += ECON16.thaw`（0.6），記下 `s.thawNight`，白天面板顯示 `D.FLOOD_TEXT.thaw`。
6. **畫面**：場景在寒潮季把水面畫成靜止的冰（有裂紋、反光，沒有波紋），基本天氣是慢慢落下的雪；`weather-fx.js` 加凍雨、大雪、冰封。減少動態效果時是靜止的一格（沿用場景原有的做法）。創作桌的夜景在 WO-16-10 已經支援寒潮。
7. **第五季「急凍」開放**：全部系統加上 `cold`、全部稀有度、收藏家是淨化派（補寫了淨化派的收藏文字），目標倍率見校準記錄。通過第四季之後開放；第六至八季仍在興建中。

## 和工單不同的地方

- **「大雪」的 id 用 `heavysnow`**：規格寫 `snow`，但 `snow` 已經是奇怪天氣「熱帶落雪」。`vis` 也是 `heavysnow`（比熱帶落雪更密、更大片）。總規格 §8.3 已更正。
- **寒潮不是所有五輪模式的局都有**：第十七期之後由章節控制（第五季、全城篩選）。原本的「遇到寒潮季的局 55% 至 75%」只適用於全城篩選和第五季。
- 「取暖」（`heater`）照總規格的條件不做：素材庫裏沒有對應的擺設。
