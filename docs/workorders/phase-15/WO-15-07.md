# WO-15-07：收工演出、結束面板與市集介面

| 項目 | 內容 |
|---|---|
| 期數 | 第十五期（總規格 §8、§11、§12） |
| 依賴 | WO-15-06 |
| 規模 | 大（約 350 行） |
| 分支 | `gemini/wo-15-07-night-shop-ui` |
| 可以改的檔案 | `game/js/craft.js`、`game/js/main.js`、`game/js/ui.js`、`game/css/polish.css`、`tools/smoke-rounds.js`、`docs/shots/` |
| 不可以改 | 邏輯檔案 |

## 目標

創作桌在五輪模式顯示今晚的目標、一到目標就收工並有演出；結束面板帶玩家去市集；市集可以買物件、開素材包、用工作室服務、上技法課、拿遺物。

## 規格

### 1. 創作桌（`craft.js`，只在五輪模式生效）

- `renderGoal`：頂部的進度條改為今晚目標：加 class `night`，標籤「今晚目標」，進度 = `IE.Stages.stageScore(ses) / ses.stage.target`，數字「已得 / 目標」。
- 標題副行：`第 k／15 晚・<種類>`（取代「本季訊號」相關文字）。
- **收工**：`doPlay` 演出完之後，如果 `IE.Rounds.cleared(s)`：
  1. 在畫面中央顯示 `.ct-cleared`：大字 `ROUND_TEXT.cleared`，下面一行 `ROUND_TEXT.early`（`n` = 剩下的下筆、`v` = `ECON.earlyBonus`；`n` 是 0 時不顯示這行）；音效 `A().sfx('combo')`、閃光、粒子；約 900 毫秒（受速度影響，點擊可跳過）。
  2. 然後呼叫 `endNight()`。
- 下筆用完而未達標：照舊結束。
- **「離開」按鈕**：第一筆之前隱藏（否則玩家可以離開再進入，重新洗牌）；第一筆之後按「離開」＝提早結束今晚（照舊呼叫 `endNight()`），未達標就是失敗。重新載入時照舊回到同一手牌（`s.session` 已存檔）。
- `endNight` 的結束面板（五輪模式）：
  - 照舊顯示今晚的作品（第十四期的作品卡）。
  - 關卡結果：通過時顯示獎金 `+$X`（其中提早收工 `+$Y`）、超額兩倍的火花；失敗時顯示 `ROUND_TEXT.failed` 和剩下的機會（●●○）。
  - 不顯示「本季訊號」進度條。
  - 按鈕 `[data-end="shop"]`：文字 `ROUND_TEXT.toShop`；如果 `s.ended`（機會用完）文字改為「看結局」。

### 2. 市集（`ui.js` 的新函數 `shopModal(s)`、`packModal(s)`、`pickModal(s)`；`main.js` 的新函數 `roundsShop()`）

- `openCraft` 的完成回呼：五輪模式 `roundsGo()`（`s.phase` 已經是 `'shop'` 或 `'ended'`）。
- `roundsShop()`：`IE.Rounds.shopOpen(s)`、音樂 `music('shop')`、`UI.modal(UI.shopModal(s), handlers)`；每次購買後重新繪畫。
- 市集視窗 `.rd-shop` 的版面（由上至下）：
  1. 標題 `ROUND_TEXT.shopTitle`；右邊顯示錢，以及本輪租金和「還差 $X」或「已足夠」（每輪最後一晚之後特別顯眼）。
  2. 遺物（只在每輪最後一晚之後）`.rs-relic`：`ROUND_TEXT.relic`，三件物件，拿了一件之後其他變灰。
  3. 靈感物件：兩件 `.rs-item[data-slot="obj:<id>"]`，顯示圖示（`IE.Icons.obj`）、名稱、流派、說明、價錢；重抽按鈕 `[data-do="objreroll"]` 顯示價錢。
  4. 素材包：兩個，顯示名稱、會出現的情緒（彩色小點）、價錢。
  5. 工作室服務、技法課（顯示配色的名稱、現在等級、升級後的籌碼 × 倍率）、工具卡：各一格。
  6. 底部：「管理物件」（沿用 `openObjects`，關閉後回到市集）、離開 `[data-do="leave"]`（`ROUND_TEXT.leave`）。
- 買了的格子顯示「已買」；錢不夠的按鈕 `disabled` 並顯示價錢。
- 開包 `packModal(s)`（`.rd-pack`）：三張素材卡（沿用 `cardHtml`，顯示星級），按一張（`.rp-card[data-i]`）就選；不可以關閉。
- 工作室服務 `pickModal(s)`（`.rd-pick`）：顯示全部素材（沿用 `cardHtml`，按星級排序），按一張（`.cardpick[data-uid]`）就套用；可以取消（`IE.Rounds.cancelPick`）。打磨時每張卡顯示該卡的打磨價錢；不能選的卡（愧疚、★5）變灰。
- 離開：`IE.Rounds.leaveShop(s)`，然後 `roundsGo()`。

### 3. 煙霧測試（延伸 `tools/smoke-rounds.js`）

接上 WO-15-06 的步驟：

6. 創作桌：每次用 `IE.Create.bestPlay(s)` 選牌並下筆，直到 `.ct-end` 出現。如果達標，檢查曾經出現 `.ct-cleared`。
7. 按 `[data-end="shop"]`，看到 `.rd-shop`、兩件 `.rs-item[data-slot^="obj:"]`、兩個素材包。
8. `s.cr = 500`（用 `window.__IE.Game.state`），重新繪畫，買一個素材包，在 `.rd-pack` 選第一張：素材庫多一張。
9. 買工作室服務（第 1 晚是燒掉），在 `.rd-pick` 選一張：素材庫少一張。
10. 按離開：看到第 2 晚的 `.rd-day`。
11. 重新載入頁面，按「繼續」：仍然是第 2 晚的白天。
12. 沒有 JS 錯誤。
