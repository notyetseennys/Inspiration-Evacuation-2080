## 目標

令角色線、朋友線、阿星線和今日快訊在邏輯上運作：模擬器可以玩到故事的每一章，單元測試覆蓋所有規則。介面在 WO-15-13 接上。

## 規格

### 1. `game/js/story.js`（`IE.Story`，UMD，寫法照 `rounds.js`）

照總規格 §14 實作，匯出：

| 函數 | 用途 |
|---|---|
| `init(s)` | 五輪模式的 `newRun` 呼叫，建立 `s.story`、`s.nightMod`、`s.rentMod`（舊存檔沒有時，其他函數也要自動建立） |
| `plan(s)` | 每輪第一天決定本輪的收藏（§14.4.1） |
| `chapter(s)` | 今天的章（§14.3），設 `pending` |
| `choose(s, i)` | 回答 `pending` 的章，回傳報告 |
| `fx(option)` | 選項的效果清單（格式同 `R.optionFx`），給介面顯示 |
| `hide(s, npc)` | 把朋友藏起來（§14.4.3），回傳 `{ ok, msg, cost }` |
| `collect(s, rep)` | 篩選日的收藏（§14.4.4），由 `IE.Rounds.review` 呼叫 |
| `astar(s)`、`feed(s)`、`fate(s)` | 阿星、今日快訊、朋友近況（§14.5） |
| `epilogue(s)` | 結局用（§14.4.5） |

- 只用 `R.rand`、`R.pick`；`feed` 不可以用隨機數。
- 角色還沒有內容（`D.STORY.lines[bg]` 不存在）時，`chapter` 回傳 null，其他照常。
- 收藏的文字：朋友沒有這個種族的 `why`、`fate` 時（改抽其他朋友），用 `D.STORY.species[種族]` 的通用文字（§14.4.1）。

### 2. 接上現有的邏輯

- `rules.js` 的 `newRun`（五輪分支）：`IE.Story && IE.Story.init(s)`。
- `rounds.js`：
  - `offer`：本輪第二天，第二張卡固定是 `friend:<本輪收藏的朋友>`（朋友不在、已經藏起來或被收藏就照舊）；
  - `choose` 的朋友卡：選了本輪收藏的朋友就記下 `met`；
  - `review`：交租和秤重之後、`advance` 之前呼叫 `IE.Story.collect(s, rep)`（機會用完時不呼叫）；
  - `target`：讀 `s.nightMod`（只影響那一晚）；`rentOf`：讀 `s.rentMod`（只影響那一輪）；
  - `fx.chance` 令機會變成 0 時，照 `loseChance` 進入「人才庫」結局。

### 3. `tools/sim-rounds.js`

- 載入 `data-story.js`（在 `data-rounds.js` 之後）和 `story.js`（在 `rounds.js` 之後），見總規格 §2。
- 白天的流程照 §14.3：`R.morning` → `IE.Story.plan` → `IE.Story.chapter`（有章就按策略選，那一天不抽道德抉擇）→ 道德抉擇 → 生活卡。
- 選章的策略：
  - `balanced` 選 `both`，沒有就選第一個；
  - `worker` 選 `survive`；`liver` 選 `peak`；
  - `saint` 選 `sin` 最少的（相同時選有 `atone` 的）；
  - `shameless` 選 `cr` 最多的；
  - `random` 用 `R.pick`。
- 藏朋友的策略：
  - `balanced`：錢夠「本輪租金 + hideCost + 60」就藏；
  - `saint`、`liver`：錢夠「本輪租金 + hideCost」就藏；
  - `worker`、`shameless` 從不藏；
  - `random` 錢夠就用 `R.rand() < 0.5` 決定。
- 輸出多兩項：每局平均回答幾章、朋友被收藏／藏起來的平均人數。
- 跑 `node tools/sim-rounds.js 200`，把結果和 WO-15-09 的數字並排寫在 `CALIBRATION.md` 新的一節。**不要調整 `ECON`**：如果勝率離開 WO-15-09 的範圍，在提交訊息寫明，由 Claude 決定。

### 4. 單元測試 `tools/tests/story.test.js`

1. 新局有 `s.story`；舊存檔（刪掉 `s.story`）呼叫任何函數都不會出錯。
2. 每輪第一天有章，同一天重複呼叫回傳同一章；回答之後 `done`、`log`、`side` 正確，`pending` 清除。
3. `if`、`unless`：第 1 輪的選擇令第 2 輪出現不同的章（用 `copywriter`）。
4. 每一種 `fx` 都正確套用（錢、火花、靈魂、素材、物件、配色、熟絡度、機會、`target`、`rent`、`notice`、`set`）。
5. `target` 只影響下一晚；`rent` 只影響本輪。
6. 收藏預告：同一個種子結果相同；候選按 `collectors`；候選都不在浮城時改抽其他朋友，文字用種族的通用文字；一位朋友都不在就沒有收藏；第 5 輪沒有。
7. 第二天的生活卡有這位朋友的朋友卡；選了之後記下 `met`。
8. `hide`：扣錢、錢不夠失敗、篩選日不會被收藏、`notice` 加一。
9. `collect`：見過最後一面得到贈物；沒見得到紙條素材；朋友 `alive` 變成 false；下一晚 `fate` 有近況。
10. `astar`、`feed`：對應正確；`feed` 前後 `rngState` 不變。
11. 「存檔再載入」（JSON）之後，`pending` 的章仍然在，可以回答。
12. `epilogue`：結語按旗標選擇；朋友的狀態和光譜正確。
