# WO-15-03：夜晚的規則（目標、收工、獎金、失敗）

| 項目 | 內容 |
|---|---|
| 期數 | 第十五期（總規格 §3、§5、§6） |
| 依賴 | WO-15-01 |
| 規模 | 中（約 150 行） |
| 分支 | `gemini/wo-15-03-nights` |
| 可以改的檔案 | `game/js/rounds.js`、`game/js/create.js`（只限 `start`、`canStart`、`finish`）、`game/js/stages.js`（只限 `stageOn`、`resolve`）、新檔 `tools/tests/rounds-night.test.js` |
| 不可以改 | 其他所有檔案（`craft.js` 的收工演出在 WO-15-07） |

## 目標

令創作桌在五輪模式按新規則運作：固定的手牌、下筆和改稿數目，目標來自 `IE.Rounds.target`，一到目標就可以收工，按規則發獎金或失去機會。

## 規格

### `stages.js`

- `stageOn(s, day)`：五輪模式時，`target` 改為 `IE.Rounds.target(s, day / 4)`（其他欄位照舊：`kind`、`rules`、`index` 等）。舊模式完全不變。
- `resolve(s, stage, score)`：五輪模式時用新的獎勵分支（舊模式完全不變）：
  - 通過：`reward = IE.Rounds.nightReward(s, stage.kind, playsLeft)`（`playsLeft` 由 `IE.Create.finish` 傳入，見下），`s.cr += reward`、`s.stats.crEarned += reward`；分數達到目標兩倍：`R.addSpark(s, ECON.overkillSpark, true)`，外星評審和聯展再加一張金色扭蛋券（照舊的寫法）。**不發工具卡、不發銀色扭蛋券、不送物件**（第十五期這些改由市集提供）。
  - 失敗：`R.addSpark(s, ECON.failSpark, true)`，`IE.Rounds.loseChance(s, 'night')`。
  - 兩者都：`s.nightLog.push({ night: s.night, kind, target, score, pass, reward, playsLeft })`，`s.stageDone[s.day]` 照舊記錄，外星評審圖鑑照舊記錄。
  - 回傳的物件照舊（加上 `reward`、`playsLeft`），令結束面板可以顯示。

### `create.js`

- `canStart(s, mode)`：五輪模式只接受 `'normal'`；材料費當作 0（不檢查錢）；只檢查素材庫至少 3 張。火花不會低於 1（WO-15-01 已處理）。
- `start(s, mode)`：五輪模式時：不扣材料費、不扣身體、不設通宵；`handSize`、`plays`、`discards` 的**基本值**改用 `ECON.hand`、`ECON.plays`、`ECON.discards`（物件、角色、外星評級、世界事件的加減照舊）；不是速寫。之後設定 `s.phase = 'night'`、`s.slot = 2`。
- `finish(s)`：五輪模式不結算天空區委託（不呼叫 `IE.World.settleCommissions`，`paid` 是空陣列）。五輪模式時，把 `playsLeft = ses.plays` 傳給 `IE.Stages.settle`（改為 `settle(s, ses, playsLeft)`，再傳給 `resolve`；舊模式不傳，行為不變），結算之後設定 `s.phase = s.ended ? 'ended' : 'shop'`。其他（作品、作品集、委託）照舊。

### `rounds.js`

```js
nightReward(s, kind, playsLeft) // 總規格 §6 的獎金公式；不乘外星評級的價錢修正
cleared(s)                      // s.session 存在、有 stage，而且 IE.Stages.stageScore(s.session) >= stage.target
loseChance(s, cause, rep)       // s.chances--、s.lost.push(cause)；rep 有的話加一行 ROUND_TEXT.failed 或相應文字；
                                // 機會用完：s.ended = R.endingFor(s, cause === 'soul' ? 'heavy' : 'archived')、s.phase = 'ended'
startNight(s)                   // 呼叫 IE.Create.start(s, 'normal') 並回傳 session；s.phase 必須是 'night'（否則回傳 null）
```

- **收工**：邏輯層不會自動結束；介面（WO-15-07）和模擬器在每次下筆之後檢查 `cleared(s)`，是的話呼叫 `IE.Create.finish(s)`。下筆用完時照舊由介面結束。
- 「只計最後一筆」的評審規則（`lastOnly`）沿用 `stageScore`。

## 測試：新檔 `tools/tests/rounds-night.test.js`

測試裡的「下筆」一律用 `IE.Create.bestPlay(s).uids` 再 `IE.Create.play(s, uids)`。

1. `夜晚：創作桌的數目`：copywriter、沒有物件（`s.objects = []`）時 `startNight` 之後 `handSize === ECON.hand`、`plays === ECON.plays`、`discards === ECON.discards`；錢不變；`s.session.stage.target === IE.Rounds.target(s, 1)`。
2. `夜晚：外星評審有規則`：第 3 晚（`s.night = 3`、`s.day = 12`）的 `s.session.stage.rules.length >= 1`。
3. `夜晚：一筆就收工`：把 `s.session.stage.target` 設為 1，下筆一次後 `cleared(s) === true`；`finish(s)` 之後錢增加 `ECON.nightPay.small + ECON.earlyBonus × 3`、`s.phase === 'shop'`、`s.nightLog[0].pass === true`、`playsLeft === 3`。
4. `夜晚：失敗失去一次機會`：把目標設為 1e15，下筆直到用完，`finish` 之後 `s.chances === 2`、`s.lost` 是 `['night']`、`s.nightLog[0].pass === false`、`s.phase === 'shop'`。
5. `夜晚：三次失敗就結局`：`s.chances = 1` 再失敗一次，`s.ended.type === 'archived'`、`s.phase === 'ended'`。
6. `夜晚：超額兩倍火花上升`：目標設為 1、`s.spark = 2`，一筆收工後 `s.spark > 2`。
7. `夜晚：獎金隨輪數上升`：`nightReward(s, 'boss', 0)` 在第 1 輪是 140、第 5 輪（`s.night = 15`）是 `round(140 × 2)` = 280。
8. `夜晚：舊模式不變`：標準模式第 4 天的 `IE.Stages.stageOn(s, 4).target` 和改動前相同（寫死改動前的數值）。
