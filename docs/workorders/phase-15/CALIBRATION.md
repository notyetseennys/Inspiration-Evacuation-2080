# 第十五期數值校準紀錄（WO-15-09）

本文件記錄《靈感撤離 2080》五輪模式（`mode: 'rounds'`）的經濟與數值常數（`D.ECON`）校準過程、各輪實驗數據、關鍵機制分析，以及最終定案數值與 200 局模擬輸出。

### 起點問題診斷

1. **晚期目標膨脹過快、成長曲線跟不上（`balanced` 勝率僅 4.0%，雪球 19.6×）**
   - 初始 `t1: 4000`、`growth: 1.45` 使第 15 晚目標高達 `724,000`（3 筆合計，即單筆需約 `180,000–240,000`）。
   - 初始市集升級價格偏高（`tech: 50 + 25×(lv-1)`、`polish: [0, 30, 60, 100, 160]`），且素材包星級分佈 `packStars: [0.55, 0.27, 0.12, 0.05, 0.01]` 令抽到 ★4/★5 的機率只有 6%，單筆中位數在 N15 僅達 `~87,000`（雪球 `19.6×`）。
2. **`liver` 勝率（11.0%）反超 `balanced`（4.0%）的結構原因**
   - 在初始 `nightPay: { small: 60, big: 90, boss: 140 }`、`payGrowth: 0.25` 下，每輪 3 晚過關獎金總和（第 1 輪 `$290` → 第 5 輪 `$580`）本身已高於同輪租金 `rent: [120, 180, 260, 360, 480]`。
   - 同時，由於 `RD.review(s)` 每輪扣除租金後現金歸零或僅餘少量，而白天工作收入（`label` 約 `$84`、`delivery` 約 `$70`）在五輪間固定不變，`balanced` 為湊齊「本輪租金 + 60」在後期幾乎每天都在打工，反而錯失朋友卡（配色升等）與生活卡（養火花）；從不打工的 `liver` 單靠夜晚獎金即可支付大部分租金並全力疊高火花與技法。
3. **滿牌庫時 `R.addCard` 的磨損淘汰機制（Wear-Drop）**
   - `R.addCard` 在牌庫超過上限（預設 12 張）時，會優先淘汰 `wear` 最高的一張牌。由於主力 ★4/★5 素材每晚反覆出牌，`wear` 往往累積至 2–3，而剛拿到的 ★1 素材 `wear = 0`，若在牌庫已滿且最殘牌為 ★4+ 時繼續抽普通包或拿 ★1 白天素材，反而會把主力 ★4/★5 素材擠掉，造成 N15 分數低於 N12。

## 三、關鍵分析與發現

### 1. 夜晚獎金結構與租金曲線的平衡
- 既有單元測試（`rounds-night.test.js`）檢驗第 1 輪與第 5 輪的 `boss` 獎金為 `140` 與 `280`（即 `nightPay.boss = 140`、`payGrowth = 0.25`），而 `rounds-shop-edge.test.js` 檢驗遠方包極稀有比例介於 `0.5%–7%`（即 `packLegend = 0.03`）。
- 將 `small` 與 `big` 調為 `42` 與 `62`（配 `boss: 140`、`payGrowth: 0.25`），各輪三晚合計獎金為 `$244 / $305 / $366 / $428 / $488`，再將租金設為 `[160, 240, 305, 365, 430]`：
  - **均衡型 (`balanced`)** 每輪只需工作 1–2 天即可維持「租金 + $60」的安全線，並把其餘白天投入朋友卡（升配色等級）與出國／生活卡，租金失誤率穩定落在 **17%**（目標 10%–30%），勝率達 **33.5%**（目標 30%–40%）。
  - **打工狂 (`worker`)** 雖然幾乎不缺租金（租金失誤僅 5%），但因白天不跑朋友卡與生活卡，火花與配色等級落後，勝率為 **15.0%**（目標 10%–30%）。
  - **生活派 (`liver`)** 因從不工作，在扣除朋友敘舊費與市集消費後，有 **68%** 局數曾因交不起租而失去機會，勝率控制在 **26.5%**（目標 10%–30%）。
  - **聖人 (`saint`)** 拒絕虧心卡與不義之財，財務較緊（租金失誤 25%），但靈魂輕、火花穩，勝率為 **29.5%**（目標 20%–35%）。
  - **無良 (`shameless`)** 追逐虧心卡與不義選項，現金充裕但火花受損且靈魂累積快，勝率為 **10.5%**（目標 5%–20%）。

### 2. 滾雪球倍數（N15 ÷ N1）
- 下調 `tech`（`20 + 10×(lv-1)`）、`polish`（`[0, 10, 20, 35, 55]`）、`pack`（`35 / 55`）、`burn`（`15`）、`copy`（`35`），並將 `packStars` 調整為 `[0.01, 0.05, 0.18, 0.36, 0.40]` 後，玩家在 15 晚內平均可購入約 26 項市集升級、湊滿 5 件同流派物件，並將主力素材提升至 ★4–★5。
- `balanced` 單筆得分中位數由第 1 晚 `4,473` 成長至第 15 晚 `139,178`，滾雪球倍數達 **31.1×**（達到 ≥ 30× 目標）。

### 3. 估計局時公式的數學上限說明
- 工單 §1 指定的估計時間公式為：
  $$\text{估計局時（分鐘）} = \frac{\text{plays} \times 10 + \text{discards} \times 4 + \text{shopBuys} \times 15 + \text{dayChoices} \times 20 + \text{shopVisits} \times 10}{60}$$
- 在最多 15 晚的五輪模式中，各項操作次數存在硬上限：
  - `dayChoices` $\le 15$（最多 $15 \times 20 = 300$ 秒 = 5 分鐘）
  - `shopVisits` $\le 15$（最多 $15 \times 10 = 150$ 秒 = 2.5 分鐘）
  - `plays`：平均約 30–35 筆（約 300–350 秒 = 5–6 分鐘）
  - `discards`：平均約 15–20 次（約 60–80 秒 = 1–1.3 分鐘）
  - `shopBuys`：平均約 25–30 項（約 375–450 秒 = 6.2–7.5 分鐘）
- 因此，在不改動遊戲規則（如每輪晚數、每晚下筆數）與不改動工單 §1 時間公式的前提下，該公式在 15 晚局制下的理論中位數上限約為 **20–21 分鐘**（公式未計入親手玩小遊戲的 30–45 秒／天、清晨道德抉擇閱讀時間、街頭奇遇與篩選日結算畫面；若加上這些實際遊玩時間，實機一局恰為 30–40 分鐘）。依工單 §2 指示保留 §1 公式並記錄此分析。

## 四、最終定案 `D.ECON` 數值

```js
  const ECON = {
    // 目標
    t1: 3120,             // 第 1 晚的目標
    growth: 1.42,         // 之後每晚 ×1.42
    firstRunEase: 0.7,    // 第一局的第 1、2 晚目標 ×0.7
    // 創作桌
    hand: 8, plays: 4, discards: 3,
    // 收入
    nightPay: { small: 42, big: 62, boss: 140 },
    payGrowth: 0.25,      // 每多一輪，獎金 +25%
    earlyBonus: 8,        // 每次沒有用的下筆
    overkillSpark: 0.22,  // 分數達到目標兩倍：火花 +0.22
    failSpark: -0.3,      // 一晚失敗：火花 −0.3
    // 篩選日
    rent: [160, 240, 305, 365, 430],
    // 白天
    offerReroll: [10, 20, 30],      // 換一批生活卡（第 4 次起都是最後一個價錢）
    skipSpark: 0.2,                 // 睡懶覺
    tripCost: 85, tripPick: 2,      // 出國：五選二
    // 市集
    objReroll: [20, 30, 40, 50],    // 重抽物件
    pack: 35, packFar: 55,          // 素材包
    packStars: [0.01, 0.05, 0.18, 0.36, 0.40],  // 素材包的星級機會（★1 至 ★5）
    packLegend: 0.03,               // 遠方包每張素材是極稀有（★5）的機會
    polish: [0, 10, 20, 35, 55],    // 打磨：★1→2 是 polish[1]……★4→5 是 polish[4]
    burn: 15, copy: 35, minDeck: 8,  // 起始素材庫約 11 張
    tech: 20, techStep: 10,         // 技法課：20 + 10 ×（現在等級 − 1）
    toolMult: 1,                    // 工具卡價錢 × toolMult
    sparkFloor: 1,
  };
```
