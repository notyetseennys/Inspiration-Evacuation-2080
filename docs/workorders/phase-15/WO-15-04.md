# WO-15-04：市集的規則（物件、素材包、工作室服務、技法課、遺物）

| 項目 | 內容 |
|---|---|
| 期數 | 第十五期（總規格 §8） |
| 依賴 | WO-15-01、WO-15-03 |
| 規模 | 大（約 300 行） |
| 分支 | `gemini/wo-15-04-shop` |
| 可以改的檔案 | `game/js/rounds.js`、`game/js/rules.js`（只限：匯出 `pickObjects`）、新檔 `tools/tests/rounds-shop.test.js` |
| 不可以改 | 其他所有檔案 |

## 目標

每晚之後的市集：純邏輯，介面在 WO-15-07。

## 規格

在 `IE.Rounds` 加入：

```js
shopOpen(s)              // s.phase 必須是 'shop'；這一晚還沒有 s.shop 就按總規格 §8 產生，回傳 s.shop
price(s, slot)           // 回傳價錢（整數，已乘 stakeMod(s, 'prices')）；slot 見下表
shopBuy(s, slot)         // 回傳 { ok, msg, pack?, pick? }
objReroll(s)             // 重抽兩件物件：價錢 ECON.objReroll[min(objRerolls, 長度 − 1)]；回傳 { ok, msg }
packPick(s, i)           // 從 s.pack 選第 i 張（0..2）；回傳 { ok, msg, card }
pickCard(s, uid)         // 為 s.pick 的服務選一張素材；回傳 { ok, msg }
cancelPick(s)            // 取消選素材：退回服務的錢，清除 s.pick，'service' 從 bought 移走
leaveShop(s)             // s.pack 或 s.pick 未完成時回傳 { ok: false }；否則：每輪最後一晚 → s.phase = 'review'；其他 → IE.Rounds.advance(s)（WO-15-05 實作；這張工單先寫一個只設定 night、day、phase、offer、shop 的簡單版本，WO-15-05 會替換）
```

| slot | 價錢 | 買了之後 |
|---|---|---|
| `obj:<id>` | `D.OBJ_PRICE[rarity]` | 先檢查放得下（見下面），再 `R.gainObject(s, id, null)`、扣錢；從 `s.shop.objs` 移走 |
| `pack:<pid>` | `ECON.pack`（遠方包 `ECON.packFar`） | 扣錢，產生 `s.pack`（見總規格 §8），回傳 `{ pack: s.pack }` |
| `service` | 打磨 `ECON.polish[星級]`（要選了素材才知道星級，所以**付款延後到 `pickCard`**）；燒掉 `ECON.burn`；複印 `ECON.copy` | 設定 `s.pick = { service }`，回傳 `{ pick: s.pick }`；燒掉和複印立即扣錢，打磨在 `pickCard` 扣錢 |
| `tech` | `ECON.tech + ECON.techStep × (現在等級 − 1)` | `s.forms[id] = 等級 + 1`；報告文字「技法課：X 升到 Lv.N」 |
| `tool` | `IE.Stages.toolPrice(s, id) × ECON.toolMult` | `IE.Stages.giveTool` 成功才扣錢 |
| `relic:<id>` | 0（第一件）；`relic.taken` 之後不可以再拿 | `R.gainObject`；`relic.taken = true` |

- 每項（物件除外）只可以買一次，記在 `s.shop.bought`。錢不夠回傳 `{ ok: false, msg: '要 $X' }`，狀態不變。
- 物件欄和儲物箱都滿了的時候不可以買物件或拿遺物：**先檢查** `R.canEquip(s, id) || s.objStash.length < 4`，不成立就回傳 `{ ok: false, msg: '物件欄和儲物箱都滿了' }`，**不要呼叫 `R.gainObject`**（它在兩欄都滿時會自動把物件賣掉並加錢，會變成刷錢的漏洞）。
- `pickCard`：
  - 打磨：卡不可以是愧疚素材、★5；扣 `ECON.polish[現在星級]`，星級 +1（設定 `card.star`）。
  - 燒掉：素材庫張數必須大於 `ECON.minDeck`；從 `s.cards` 移除。
  - 複印：用 `R.addCard` 加入副本（`wear: 0`，名字加「（副本）」，保留 `star`、`tags`、`medium`、`mod`）。
  - 成功之後清除 `s.pick`。
- 素材包的抽卡：用 `R.rand`；三張素材定義互不相同；星級按 `ECON.packStars` 的累積機會擲（極稀有一律 ★5）。`packPick` 用 `R.addCard(s, id)` 再設定 `card.star`。
- 第一局（`s.firstRun`）第 1 晚的市集：兩件物件中至少一件是稀有（`rarity: 'rare'`），沒有就把第二件換成一件稀有物件。
- 遺物（每輪最後一晚之後）：`relic = { items: R.pickObjects(s, 3, s.shop.objs), taken: false }`。

### 需要的小改動

- `rules.js`：把 `pickObjects` 加入 `IE.Rules` 的匯出（函數本身不改）。

## 測試：新檔 `tools/tests/rounds-shop.test.js`

準備：五輪模式新局，`s.phase = 'shop'`，`s.cr = 1000`。

1. `市集：內容`：`shopOpen` 之後有 2 件物件、2 個不同的素材包、1 項服務、1 堂技法課、1 張工具卡；第 1 晚沒有遺物，第 3 晚（`s.night = 3`）有 3 件遺物。
2. `市集：服務輪流`：`s.night` 為 1、2、3 時服務依次是 burn、copy、polish。
3. `市集：買物件`：買 `obj:<第一件>` 之後物件在 `s.objects` 或 `s.objStash`，錢少了物件價錢，`s.shop.objs` 只剩一件；`s.cr = 0` 時買第二件失敗，狀態不變。
4. `市集：素材包`：買一個素材包之後 `s.pack.cards` 有 3 張不同的素材；`packPick(s, 1)` 之後素材庫多一張、星級在 1 至 5 之間、`s.pack === null`；`leaveShop` 在選之前回傳 `ok: false`。
5. `市集：打磨`：服務是打磨時，選一張 ★1 素材，錢少了 `ECON.polish[1]`、星級變 2。
6. `市集：燒掉有下限`：服務是燒掉、素材庫剛好 `ECON.minDeck` 張時 `pickCard` 失敗；多一張時成功、張數 −1。
7. `市集：複印`：副本的標籤、星級和原本相同，`wear === 0`。
8. `市集：技法課越來越貴`：買技法課之後該配色升一級；同一配色第二次的價錢多 `ECON.techStep`。
9. `市集：遺物只可以拿一件`：第 3 晚的遺物第一件免費（錢不變），之後拿第二件失敗。
10. `市集：重抽越來越貴`：連續重抽兩次，分別扣 20 和 30（stake 1）。
11. `市集：第一局保證稀有`：`meta: { runs: 0 }` 的新局第 1 晚，物件中至少一件是稀有（跑 20 個 seed 都成立）。
12. `市集：離開`：第 1 晚離開 → `s.night === 2`、`s.phase === 'day'`；第 3 晚離開 → `s.phase === 'review'`。
13. `市集：滿了不能買、不會刷錢`：把物件欄和儲物箱填滿，買物件失敗，錢不變，`s.objects` 和 `s.objStash` 不變。

- 價錢全部經 `price(s, slot)`，不在別處重複計算。
