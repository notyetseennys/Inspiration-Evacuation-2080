## 規格

### 1. 圖片的取得：`IE.img(name)`（新檔 `game/js/img.js`，在 `data.js` 之前載入）

- `IE.img(name)` 回傳圖片的網址：
  - 打包之後（`dist/`）：`IE.IMG[name]`（`build.js` 內嵌的 data URI），沒有就回傳空字串；
  - 開發時（`game/index.html`）：`'img/' + name + '.png'`。
- `IE.imgTag(name, cls)` 回傳 `<img class="px ' + cls + '" src="…" alt="" loading="lazy" onerror="this.hidden=true">`；網址是空字串時回傳空字串。圖片不存在時不會出現破圖。
- `name` 是不帶 `.png` 的檔名，例如 `day-label`、`friend-mary`、`end-archived`。

### 2. 打包（`tools/build.js`）

- 讀取 `game/img/*.png`，在所有遊戲腳本之前插入 `<script>window.IE=window.IE||{};IE.IMG={"day-label":"data:image/png;base64,…",…};</script>`。
- 網頁圖示：`game/index.html` 加 `<link rel="icon" href="img/icon.png">`，打包時換成 data URI。
- 打包之後印出大小；**超過 4 MB 就失敗**。
- `dist/` 直接用 `file://` 開啟也要看得到圖片。

### 3. 顯示

- 所有插圖加 `.px`：`image-rendering: pixelated`；寬度用整數倍數放大時最清楚（例如 256 寬的橫幅顯示為 256 或 512 CSS 像素），做不到時以清楚可讀為先。
- 插圖只負責氣氛，不放資訊；文字、數字照舊由介面顯示。
- 減少動態效果（`prefers-reduced-motion`）時，沒有任何圖片動畫。
- 手機 390px：沒有橫向捲動；圖片不可以把按鈕推出第一屏太多（每張圖在手機最高 120px）。
