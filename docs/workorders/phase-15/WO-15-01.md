## 目標

建立 `rounds` 模式的資料和狀態，令 Node 可以開一局五輪模式的新遊戲，並計算每晚的種類、日子和目標。**這張工單不做任何介面**；五輪模式在開局畫面暫時隱藏。

## 規格

1. `game/js/data.js` 的 `MODES` 加入（放在 `long` 之後）：
   ```js
   rounds: { id: 'rounds', name: '五輪', desc: '十五晚，約四十分鐘', days: 60, period: 12, stageDays: [4, 8, 12], season: 20,
     shopEvery: 2, sketch: false, rounds: true, hidden: true, thresholds: [1, 1, 1, 1, 1] },
   ```
   `thresholds` 只是令舊的函數不會除以零；五輪模式不使用訊號門檻。
2. 新檔 `game/js/data-rounds.js`（UMD 寫法照 `data-contacts.js`），`Object.assign(D, { ECON, ROUND_TEXT, DAYCARDS, PACKS, SERVICES })`：
   - `ECON`、`ROUND_TEXT`：**逐字照抄**總規格 §6、§11。
   - `DAYCARDS`：總規格 §7 的表，格式 `{ id, kind, micro }`（沒有小遊戲的卡不寫 `micro`）。`friend` 和 `trip` 各寫一行範本：`{ id: 'friend', kind: 'friend' }`、`{ id: 'trip', kind: 'trip', minRound: 2, chance: 0.15, origins: ['asia', 'europe', 'america', 'africa', 'arctic', 'ocean'] }`，由 WO-15-02 展開。
   - `PACKS`：總規格 §8 的表，格式 `{ id, name, tags }`；遠方包寫 `{ id: 'far', name: '遠方包', foreign: true }`。
   - `SERVICES`：`[{ id: 'polish', name: '打磨', desc: '一張素材升一星' }, { id: 'burn', name: '燒掉', desc: '從素材庫刪除一張素材' }, { id: 'copy', name: '複印', desc: '複製一張素材' }]`。
3. 新檔 `game/js/rounds.js`（UMD 寫法照 `stages.js`），建立 `IE.Rounds`，這張工單只實作：
   ```js
   on(s)                 // !!(s && D.MODES[s.mode] && D.MODES[s.mode].rounds)
   roundOf(s, night)     // night 省略時用 s.night；回傳 1..5
   kindOf(night)         // 'small' | 'big' | 'boss'
   dayOfNight(night)     // 4 × night
   sig3(v)               // 取三位有效數字：sig3(12345) === 12300；sig3(4000) === 4000；sig3(987) === 987
   target(s, night)      // 總規格 §6 的目標公式；night 省略時用 s.night
   rentOf(s, round)      // 總規格 §9 的租金（含 stakeMod 'rent'、R.worldMods(s).rentMult、perk.rentMult）；round 省略時用目前的輪
   ```
4. `game/js/rules.js`：
   - `newRun`：所有新局的 `v` 改為 `10`。如果 `D.MODES[s.mode].rounds`，在**回傳之前**加入總規格 §4 的欄位（`night: 1, phase: 'day', day: 4, slot: 0` 等）。**不可以在舊模式多用一次 `rand(s)`**（否則舊模式的模擬結果會改變）。
   - `hurt(s, v, …)` 和 `heal`：五輪模式直接 `return 0`（`heal` 直接 return）。
   - `addSpark`：五輪模式在最後把 `s.spark` 設為 `Math.max(D.ECON.sparkFloor, s.spark)`，回傳值照舊是實際變化量。
5. `game/js/main.js` 的 `savedRun`：接受 `r.v === 9 || r.v === 10`。
6. `game/js/ui-roster.js` 的模式按鈕：略過 `hidden` 的模式。
7. `game/index.html`、`tools/sim.js` 的載入清單：按總規格 §2 加入兩個新檔。

## 測試：新檔 `tools/tests/rounds-core.test.js`

每一項都要有（名稱照寫）：

1. `五輪：開局狀態`：`t.run({ mode: 'rounds' })` 的 `mode === 'rounds'`、`night === 1`、`phase === 'day'`、`day === 4`、`v === 10`、`chances === 3`、`nightLog`、`roundLog`、`lost` 都是空陣列。
2. `五輪：舊模式不受影響`：`t.run({ mode: 'standard' })` 的 `night` 是 `undefined`、`day === 1`、`IE.Rounds.on(s) === false`。
3. `五輪：時間表`：`kindOf(1..15)` 依次是 small、big、boss 重複五次；`roundOf(s, 4) === 2`、`roundOf(s, 15) === 5`；`dayOfNight(15) === 60`。
4. `五輪：目標每晚上升`：`target(s, 1) === sig3(ECON.t1)`；`k = 1..14` 時，`target(s, k + 1) / target(s, k)` 在 `ECON.growth` 的 ±1.5% 以內（三位有效數字的進位誤差）。
5. `五輪：第一局頭兩晚較易`：`t.run({ mode: 'rounds', meta: { runs: 0 } })` 的 `target(s, 1)` 等於 `sig3(ECON.t1 × ECON.firstRunEase)`；第 3 晚不打折。
6. `五輪：外星評審之夜`：`s.day = 12` 時 `IE.Stages.stageOn(s, 12).kind === 'boss'`，而且有至少一條評審規則。
7. `五輪：身體不變、火花有下限`：五輪模式 `R.hurt(s, 50, 'test')` 之後 `s.body` 不變；`R.addSpark(s, -10, true)` 之後 `s.spark === ECON.sparkFloor`。舊模式同樣的呼叫會令身體下降。
8. `五輪：租金`：`rentOf(s, 1) === ECON.rent[0]`（stake 1、沒有世界事件、copywriter）；`rentOf(s, 5) === ECON.rent[4]`。
