# 《靈感撤離 2080》美術與演出任務書

這份任務書給負責**美術、動畫、音效與介面打磨**的開發者（Gemini）。遊戲規則、數值、內容資料與平衡由 Claude 負責。兩條開發線同時進行，所以請嚴格按照下面的檔案分工。

目標只有一個：在**不改變任何玩法和分數**的前提下，令遊戲更美觀、更有手感、視覺元素更豐富。

---

## 0. 開始之前

1. 先讀 `README.md` 的「檔案結構」「創作之夜：遊戲的核心」和「媒材與十個創作流派（第七期）」三節，了解遊戲在做甚麼。
2. 從分支 `claude/serene-dirac-xqu6dg` 的最新 commit 開一條新分支，例如 `gemini/art-polish`。每完成一個任務就 commit 一次，commit 訊息寫明任務編號（例如「任務 1：121 件靈感物件的獨立圖示」）。不要 force push，不要直接改 `claude/` 分支。
3. 本機執行：
   - `node tools/serve.js`，然後開啟 <http://localhost:8080/>。
   - `node tools/smoke.js`：瀏覽器煙霧測試（需要 Playwright），**每次 commit 前都要全部通過，而且沒有 JS 錯誤**。
   - `node tools/build.js`：更新 `dist/` 的單一 HTML 檔。
4. 測試捷徑：瀏覽器 console 的 `window.__IE` 可以讀寫遊戲狀態。例如開始新一局之後執行
   `const s = __IE.Game.state; s.day = 20; s.slot = 2;`
   再切換到「房間」畫面按「創作」，就會進入第 20 天的外星評審之夜（`tools/smoke.js` 也是這樣做的）；`s.objects = ['tidegauge', 'sandbag', 'aquarium']` 可以直接裝備三件水淹流物件。

## 2. 硬性規定

- **沒有外部素材**：不加入圖片檔、音檔或 JavaScript 函式庫。所有圖像用像素字串、canvas 或 CSS／內嵌 SVG 繪畫；所有聲音用 Web Audio 即時合成。字型只用已載入的 Noto Sans HK、Silkscreen、VT323。
- **不改玩法**：不改任何 id、資料結構或計分結果。演出只讀 `IE.DATA` 和計分紀錄 `steps`。
- **文字**：遊戲內所有文字用繁體中文書面語（不用粵語口語），語氣延續現在的諷刺風格。
- **手機**：寬 360px 也要好看，不可以出現橫向捲動；觸控目標至少 40px。
- **減少動態效果**：系統設定減少動態效果時（`IE.Pixel.reducedMotion`），閃光、震動和全畫面演出要改為靜態或極短版本。
- **性能**：dataURL 和 canvas 繪畫要快取；粒子要有數量上限；計分演出在速度 ×4 和快轉時仍然流暢。
- **大小**：`node tools/build.js` 輸出的單一 HTML 檔現在約 830 KB，完成所有任務後請保持在 1.5 MB 以下。
- **截圖**：每個任務完成時，附上桌面（寬 1000px）和手機（寬 390px）的前後截圖。

## 4. 任務（按優先次序）

### P0：影響最大，請先做

#### 任務 1：121 件靈感物件各有獨立圖示
- **現況**：121 件物件只用了約 40 個形狀，主要靠配色分辨。
- **做法**：
  - `icons.js` 支援 16×16 的形狀（按字串長度判斷尺寸）。
  - `SHAPES` 加入以**物件 id** 為鍵的形狀；`IE.Icons.obj` 先找 `SHAPES[id]`，找不到才用 `o.icon`。
  - 同一流派用統一的造型語言（例如水淹流有水滴或水紋、機械流有電路、愧疚流有灰色重物）。
  - 傳說物件加一圈金色描邊和緩慢的閃光（CSS）。
- **驗收**：121 件兩兩不同；在 32px 至 40px 大小仍然認得出；收藏頁、創作桌和商店都顯示正確。

#### 任務 2：素材卡按媒材有不同卡面
- **現況**：所有素材卡都是同一張米白色卡面，只靠右上角的一個字表示媒材。
- **做法**：
  - 五種卡面紋理：紙是橫線信紙，聲是聲波，影是菲林邊或相框，身是布紋或指紋，數是格線與掃描線。用 CSS 背景或內嵌 SVG。
  - 極稀有素材加箔光，外地素材加郵戳，愧疚素材加一層陰影。
  - 標籤色條加上圖案，色弱玩家也分得出。
- **驗收**：五種媒材一眼分得出；手機上文字仍然清楚；外星評審「停電」規則（`.cc.dark`）時看不見媒材。

#### 任務 3：外星評審肖像與登場演出
- **做法**：
  - 19 條規則各畫一位外星評審（32×32 像素），配名字和三句台詞：登場、入選、落選。
  - 外星評審之夜打開創作桌時，先播約 2 秒的登場畫面：肖像滑入、規則像印章一樣蓋下、低沉的音效。點擊可以跳過。
  - 外星評級 4 以上有兩條規則時，兩位評審一起出場。
  - 社區小展和畫廊聯展也有簡單的開場字卡（社區會堂、白盒畫廊）。
- **檔案**：新檔案 `js/art-judges.js`（肖像與台詞，以 `IE.Stages.BOSS` 的 id 為鍵）、`craft.js`、`audio.js`。
- **驗收**：19 位都有；減少動態效果時直接顯示靜態卡。

#### 任務 4：計分演出升級
- **分數級數**：一筆的分數到達一萬、十萬、一百萬時，數字的顏色、字體大小、震動和粒子逐級加強；一百萬分有全畫面特寫。
- **流派觸發**（`school` 步驟）：流派欄掃過該流派顏色的光帶，並播放該流派的音色（見任務 5）。
- **再計分**（`card` 步驟的 `again`）：素材上方彈出「再一次！」。
- **手牌觸發**（`obj` 步驟的 `held`）：手牌中那一張發光。
- **傳說組合**：全畫面標題卡，顯示組合名和謎語的答案，可以跳過。
- **新紀錄**：煙花。
- **檔案**：`craft.js`、`art.css`、`audio.js`。
- **驗收**：不改變任何分數；速度 ×4 和快轉時仍然流暢。

#### 任務 5：聲音擴充
- **十個流派**各一個觸發音色，例如水淹流是氣泡，霓虹流是電流聲，機械流是數據滴答聲。
- **五種媒材**下筆時的質感音：紙是沙沙聲，聲是琴音，影是快門，身是心跳，數是撥號音。
- **事件音效**：關卡入選、落選；外星評審主題（低音加不協和和弦）；升級、成就；備忘錄的打字機聲。
- **音樂**：關卡之夜加一層鼓；外星評審之夜換調。
- **驗收**：全部用 Web Audio 合成；靜音設定有效；各音效音量平衡。

### P1

#### 任務 6：角色立繪
- 20 個角色各畫一張 24×32 的半身立繪，用於選角畫面、狀態列頭像和結局檔案。
- 稀有度外框：R 銀、SR 金、UR 彩虹。
- 人才扭蛋機抽中 UR 時有專屬演出。

#### 任務 7：流派徽章與媒材圖示
- 十個流派徽章、五個媒材圖示（12×12）。
- 用在物件格的流派標記、創作桌的流派欄、收藏頁的流派標題和牌庫的媒材分佈。
- 流派湊滿三件（3/3）時，流派欄的外框有流動的光。

#### 任務 8：創作之夜的場景
- 創作桌背景按情況改變：
  - 平常晚上：深夜的書桌和檯燈，窗外看見水位。
  - 社區小展：社區會堂。
  - 畫廊聯展：白盒畫廊。
  - 外星評審：飛碟內部。
- 通宵創作時，背景慢慢天亮。

#### 任務 9：局外畫面
- 人才檔案升級的演出。
- 成就彈出提示（toast）。
- 外星 HR 備忘錄做成「機密文件」：塗黑、印章、打字機逐字出現。
- 外星評級徽章（1 至 8 級）：選角畫面顯示每個角色已通過的最高評級（資料在 `IE.Game.meta.stakes`）。
- 每日挑戰做成一張卡片。

#### 任務 10：文字彩蛋
- 新檔案 `js/art-flavor.js`：
  - 121 件物件各一句引言，例如「天秤：『外星人說重量不重要。他們說謊。』」。
  - 十個流派各一段宣言。
- 在創作桌的物件說明和收藏頁顯示。

### P2

#### 任務 11：浮城的天氣與時間
- **季節**：風暴季是斜雨和閃電，熱浪季是熱空氣扭曲，酸雨季是綠色雨點和被腐蝕的招牌。
- **時間**：早上、下午、晚上的光線不同。
- **細節**：
  - 霓虹在水面的倒影。
  - 晚上飛碟的探射燈掃過浮城。
  - 朋友被外星人帶走之後，他家的窗口不再亮燈。

#### 任務 12：目的地的動態細節
- 30 個目的地的全景各加一至兩個會動的元素，例如海浪、飛鳥、燈籠、極光。
- 加入簡單的視差。

#### 任務 13：小遊戲的統一外框
- 11 個小遊戲用統一的開場字卡（附操作示意圖）和 HUD。
- 結算畫面的評級印章（SS 至 D）有蓋章動畫。
- 不改任何規則；傳給 `applyMicro` 的結果完全不變。

#### 任務 14：手機與無障礙
- 在寬 360px、390px 和 768px 逐頁檢查。
- 觸控目標、鍵盤焦點外框、色弱可分辨的標籤、文字對比。

#### 任務 15：創作之夜的互動教學
- 第一次創作時，改用逐步的引導取代現在的說明視窗：選牌 → 看預計分數 → 下筆 → 改稿 → 媒材 → 流派。
- 只在 `IE.Game.meta.craftTutorial` 未設定時出現，可以隨時跳過。

## 8. 背景音樂（v1.2 之後）

使用者提供了 13 首背景音樂（`game/audio/*.mp3`），由 `js/bgm.js` 按畫面播放，`README.md` 的「背景音樂」一節有完整對照表。
- `audio.js` 多了一個 `IE.Audio.music(on)`：有背景音樂時，合成的背景音樂會靜下來；音效照舊。請保留這個函式。
- 「沒有外部素材」的規定從此只適用於圖像和音效：背景音樂是例外，由使用者提供。
- 如果你的分支也改了 `audio.js` 或 `main.js`，合併時請保留 `music(...)` 的呼叫和 `bgm.js` 的 `<script>`。
