# 靈感撤離 2080（Inspiration Evacuation 2080）

> 份工越做越爽，靈魂越做越少。

2080 年，海平面暴升，浮城越高越有錢、越低越浸水。靈感強嘅人一個接一個被外星人帶走。你要打工捱過每一期租，同時保住火花，燒到大到外星人睇得見。

呢個係可以玩嘅原型（v0.1），用嚟驗證核心玩法：**爽快感由系統嚟，諷刺都由系統嚟，唔靠大量文字。**
原本嘅設計大綱：`《靈感撤離 2080》遊戲設計大綱.pdf`。

## 點樣玩

- **最快**：直接用瀏覽器打開 `dist/inspiration-evacuation-2080.html`（單一檔案，唔使安裝）。
- **開發版**：`node tools/serve.js`，然後開 <http://localhost:8080/>。

電腦用鍵盤（數字鍵揀行動、← → 標註、空白鍵陪笑、方向鍵潛水），手機直接撳畫面。建議開聲：音樂會跟你嘅火花變化。

## 核心循環

一局 30 日，每日三個時段（朝早、晏晝、夜晚），一局大約 60 至 90 分鐘。第 10、20、30 日夜晚係**篩選日**：累積訊號夠高，外星人就帶你走。

```
作品分 = 素材籌碼 × 組合倍率 × 火花 × 外星 KPI
```

| 資源 | 點樣得 | 點樣失 |
|---|---|---|
| 錢 | 打工小遊戲 | 每晚食飯、每 5 日交租、創作材料費 |
| 身體 | 休息、瞓覺 | 打工、潛水受傷、捱餓、屋企浸水 |
| 火花（倍率） | 休息、同朋友傾偈、珍藏遺物 | 打工，越熟手扣得越多 |
| 素材（籌碼） | 打工、潛水、傾偈、捱餓、隨機事件 | 創作時用掉 |

想攞高分，素材同火花兩樣都要高；但攞素材最快嘅方法（打工、受苦）正正最扣火花。

## 系統即諷刺

| 系統 | 規則 | 諷刺 |
|---|---|---|
| AI 數據標註 | 越快越準，combo 越高人工越多，但每張都扣火花 | 爽就係陷阱 |
| 熟練 = 麻木 | 同一份工做得越多，扣火花越多；火花低過 ×1 打工效率反而 ×1.3 | 麻木最有生產力 |
| 自動化 | 你每標一張圖，全城自動化升少少；50% 陪伴員職位消失，100% 標註員職位消失 | 你親手訓練取代你嘅 AI |
| 故意標錯 | 收入少，但拖慢自動化，仲會得到「反叛」素材 | 唯一嘅反抗係做差啲 |
| 情緒陪伴 | 完美笑容收入最高，扣火花最多；客人講傷心事唔可以笑 | 完美表演 = 完全失去自己 |
| 廣告 | 冇買 Premium，打工時會彈廣告遮住畫面 | 窮人稅 |
| 平台評分 | 一日冇開工就扣分，評分低過 2 星帳戶被審查 | 平台演算法 |
| 水位 | 每日升，浸到你層樓就要搬上去，租更貴 | 水位上升 = 租金上升 |
| 外星 KPI | 每季唔同，互相矛盾（例如「我哋欣賞聽話嘅人」：火花低時創作 ×1.5） | 追 KPI |
| 篩選日考績 | 外星 HR 用企業表格評你「文化契合度」「可塑性」 | 外星人 = 大企業 |
| 被選中之後 | 第一份工係同一個標註小遊戲，今次標註地球人；指引中途改，最後一個樣本好似你 | 獎勵只係同一個循環 |
| 阿星訊息 | 由 emoji 變公司 memo 再變自動回覆 | 用格式講故事，唔使旁白 |
| 跨局 | 上一局最好嘅作品會沉落舊城，下一局潛水撈得返 | 藝術比藝術家活得長 |

## 結局

- **星際特工**：被選中，做外星 HR。
- **被遣返**：被選中，但篩選地球人時評分太低（例如故意亂標）。
- **平凡人**：撐到第 30 日但冇被選中。大部分人第一次會拎到呢個。
- **死亡**：身體歸零，自動生成墓誌銘，例如「死於第 23 日。標註咗 4,812 張圖。最後作品：《浸水童年》。」
- **灰化**：連續 4 晚冇火花。你冇死，你只係唔再諗嘢。

## 平衡模擬

`node tools/sim.js [局數]` 用同遊戲一模一樣嘅規則跑唔同策略。每個策略跑 300 局嘅結果：

| 策略 | 被選中 | 平凡人 | 死亡 | 灰化 |
|---|---|---|---|---|
| 淨係打工 | 0% | 65% | 0% | 35% |
| 淨係創作（唔賺錢） | 12%（全部喺第 10 日） | 0% | 88% | 0% |
| 有節奏（打工、收集、創作輪流） | 36%（D10 6%、D20 12%、D30 18%） | 62% | 2% | 0% |
| 亂揀 | 14% | 8% | 72% | 7% |

核心矛盾成立：淨係捱唔得，淨係做自己都唔得，要搵自己嘅節奏。`DIST=1 node tools/sim.js` 會列出各策略喺每個篩選日嘅訊號分佈，用嚟調門檻。
模擬假設玩家每次都揀到最高分嘅素材組合，真人玩可能會低啲，要靠試玩再調。

## 檔案結構

```
game/
  index.html        入口
  css/style.css     介面
  js/data.js        內容：素材、組合、KPI、背景、季節、事件、文字
  js/rules.js       規則核心（純邏輯，瀏覽器同 Node 共用）
  js/audio.js       Web Audio 合成音樂同音效（火花控制音樂層數）
  js/pixel.js       像素畫引擎（320×180，文字另外高解像度畫）
  js/scene.js       浮城、水位、探射燈、牽引光束、外星辦公室
  js/micro.js       小遊戲：標註、陪笑、潛水、外星篩選
  js/craft.js       創作介面同爆分演出
  js/ui.js          HUD、手機、結算、考績表、結局
  js/main.js        遊戲流程同存檔
tools/
  sim.js            平衡模擬
  smoke.js          瀏覽器煙霧測試（要 Playwright）
  serve.js          本地伺服器
  build.js          打包成單一 HTML（dist/）
```

改完 `game/` 之後跑 `node tools/build.js` 更新 `dist/`。冇外部素材：所有圖都係程式畫，所有聲都係即場合成。

## 下一步（建議）

1. **試玩**：俾 5 至 10 個唔識你嘅人玩，觀察：
   - 佢哋有冇講出「明知會冇晒火花，但係好爽停唔到」？
   - 死咗嘅人知唔知點解死？
   - 有冇人主動開第二局？
2. **調數**：按試玩結果改 `data.js` 同 `rules.js` 嘅數值，再跑 `tools/sim.js` 確認策略分佈。
3. **內容**：加多啲素材、組合、事件同 KPI，令第二、三局有新嘢。
4. **正式版**：玩法驗證之後，可以考慮轉去 Godot 做 Steam 版，美術同音樂找人重做。
