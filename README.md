# 靈感撤離 2080（Inspiration Evacuation 2080）

> 工作越做越爽，靈魂越做越少。

2080 年，海平面暴漲，浮城越高越富有、越低越淹水。靈感強的人一個接一個被外星人帶走。你要打工撐過每一期租金，同時守住心中的火花，讓它燒得夠旺，旺到外星人看得見。

這是一個可以遊玩的原型（v0.4），用來驗證核心玩法：**爽快感來自系統，諷刺也來自系統，而不是靠大量文字。**
原始設計大綱見 `《靈感撤離 2080》遊戲設計大綱.pdf`。

## 如何遊玩

- **最快的方式**：直接用瀏覽器開啟 `dist/inspiration-evacuation-2080.html`（單一檔案，無須安裝）。
- **開發版本**：執行 `node tools/serve.js`，然後開啟 <http://localhost:8080/>。

電腦可用鍵盤與滑鼠，手機可直接觸控畫面與下方按鈕。建議開啟聲音，音樂會隨你的火花變化。

## 核心循環

一局 **100 天**，每天分早上、下午、晚上三個時段。第 20、40、60、80、100 天晚上是**篩選日**：外星人只要**又亮又輕**的人。累積訊號要夠高，靈魂重量又不能超過 21 克，外星人才會把你帶走。每個篩選日前兩晚，外星 HR 會在夢裡面試你。季節每 25 天輪替（風暴季 → 熱浪季 → 酸雨季），租金每 7 天交一次，每期上漲 3%。

```
作品分 = 素材籌碼 × 組合倍率 × 火花 × 外星 KPI
```

| 資源 | 如何獲得 | 如何失去 |
|---|---|---|
| 錢 | 五份工作、潛水、街頭表演 | 每晚吃飯、每 7 天交租、創作材料費 |
| 身體（上限由體能決定） | 休息、睡覺、聊天、吃自己抓的大魚 | 工作、潛水受傷、挨餓、家裡淹水、世界事件 |
| 火花（倍率） | 休息、聊天、街頭表演、打撈遺物 | 工作，越熟練消耗越多 |
| 素材（籌碼） | 工作、潛水、聊天、挨餓、隨機事件、道德抉擇 | 創作時用掉 |
| 靈魂重量（克） | 做虧心事：標註令人失業、附和偏見、撬別人的儲物櫃、抉擇中選擇利益 | 做義工、選擇良心、把愧疚寫進作品、購買業力抵銷額度 |
| 良知 | 做好事會慢慢恢復 | 每做一件虧心事都會被磨損 |

想拿高分，素材和火花兩樣都要高；但取得素材最快的方法（工作、受苦）正正最消耗火花。而想活下去，最容易的方法又往往會讓靈魂變重。

## 靈魂重量與良知：良知是負重

外星人篩選候選人有兩條軸：**亮**（訊號）與**輕**（靈魂重量）。火花決定你燒得多亮，靈魂重量決定你背負多少。兩者互不替代。

- **21 克的牽引光束**：外星人的光束最多只能拉起 21 克的靈魂（借用「靈魂重 21 克」的說法）。太重的人會「污染神經網絡」：訊號再高，光束也拉不動你。HR 的說法是「我們尋找沒有包袱的人」。
- **良知是負重**：每件虧心事的實際重量 = 虧心程度 × (0.3 + 0.7 × 良知)。良知越強，同一件事越重。
- **麻木**：每做一件虧心事，良知都會被磨損。越做越輕，這是一個陷阱。
- **良知也是感受力**：火花上限 = 2 + 2 × 良知。殺死良知的人很輕，但也燒不起來。
- **活下去就會變重**：AI 標註令人失業、在包廂附和有錢人的偏見（紅色音符）、撬開別人的儲物櫃，都會增加重量。每天早上約六成機會遇到一個道德抉擇，例如撿到錢包、婆婆借錢、舉報鄰居換減租、替內容農場寫假新聞，或者交出朋友的名單換取訊號。
- **卸下重量**：到避難所做義工；在抉擇中選擇良心；把「愧疚」素材寫進作品（懺悔錄、告解、罪與罰），寫出來就會變輕；或者像天空區的人一樣，花錢購買「業力抵銷額度」（越買越貴）。
- **人情**：做過三件或以上好事的人，第一次交不起租時，鄰居會湊錢替你交租。
- **看得見的重量**：浮城窗口裡的你背後有業石；潛水時業石拖在腳後，靈魂越重越往下沉；光束鎖定超重的人時，會把人拉起一點又跌回去。

三條路線各有代價：

| 路線 | 好處 | 代價 |
|---|---|---|
| 聖人 | 靈魂輕、良知高、火花上限高、可以選擇「地球守護者」 | 窮，常常要做義工，收入少 |
| 務實 | 缺錢時妥協，篩選前贖罪，被選中機會最高 | 要精打細算重量 |
| 無恥 | 錢多，可以靠出賣朋友換訊號 | 良知麻木令火花上限下降，早期的重量甩不掉，大多以「良知太重」收場 |

## 十個角色、十二項能力

開局可選十種人生：前廣告公司文案、退役潛水救生員、失業程式員、街頭樂手、外賣潛水員、退休教師、過氣網紅、黑市義體技師、夜班護士、失業動畫師。每個角色有不同的資金、火花、靈魂重量、良知、專長與十二項能力值。

| 能力 | 影響 |
|---|---|
| 體能 | 身體上限；潛水與外送速度 |
| 手速 | 標註的判斷時間 |
| 節奏感 | 陪伴與街頭表演的判定範圍 |
| 水性 | 潛水氧氣與游泳速度 |
| 技術 | 義體診所（25 以上才可接案；50 以上插座有顏色提示）；技術類選項 |
| 社交 | 聊天收穫；小費與打賞 |
| 創作 | 作品籌碼 |
| 想像力 | 火花恢復；做夢 |
| 洞察 | 看穿假新聞與騙局；隱藏選項；偏執增長較慢 |
| 冷靜 | 減少意外與受傷的損失 |
| 同理心 | 贖罪效果更好；但虧心事也更重 |
| 服從 | 工作收入更高；但會壓抑火花 |

**做甚麼就會變成甚麼**：每次行動都會訓練一些能力、磨掉另一些（例如標註提高手速與服從，卻降低想像力；表演提高節奏感與創作，卻降低服從）。成長有遞減效應。另有隱藏的**偏執**數值：寫假新聞、經歷外星人事件會令它上升；太高的人會在手機動態裡看見不存在的帖文。

## 世界事件

浮城隨時會出事。每隔一段日子就可能爆發一個世界事件，持續 1 至 10 天，改變收入、物價、靈魂重量，甚至令某些工作停擺。浮城的畫面也會隨之改變。目前共 17 種，例如：

| 事件 | 影響 |
|---|---|
| 大廈水浸 | 水位暴漲；舊城遺物更多；外送收入 ×1.5 |
| 外星人干預 | 飛碟群出現，一名朋友當場被帶走；作品訊號 ×1.3；偏執上升 |
| 世界大戰 | 物價 ×1.6、租金 ×1.2；標註收入 ×1.5，但數據被用來訓練瞄準系統（每次標註額外增加靈魂重量） |
| AI 失控 | 全城 AI 伴侶罷工：標註停擺、陪伴收入 ×2、自動化倒退 |
| 全城停電 | 多份工作停擺，但每晚火花上升 |
| 霉菌疫症 | 每天損耗身體；做義工的贖罪效果加倍 |
| 天空區週年派對 | 陪伴收入 ×2，但偏見言論更多 |
| 記憶刪除熱潮 | 商店出售「記憶刪除服務」：靈魂變輕，良知與想像力一起被刪除 |
| 外星 HR 罷工 | 篩選門檻暫時下降 |
| 其他 | 靈感稅、全城做同一個夢、外星觀光團、浮城股災、浮城選舉、舊城巨鯨、熱穹、被提教會復興 |

此外還有三十多種夜間隨機事件（部分會因能力值不同而有另一種結果），以及近四十個早上的道德抉擇（部分選項需要特定能力才可選擇）。

## 八個小遊戲

設計參考《Dave the Diver》：每份工作都有自己的手感、節奏與收集要素，而且每一份都帶著代價。

### 外送潛水（新）
- 俯瞰水淹的街道：到店舖取餐，再游到亮起的窗口送餐；最多同時背兩份。
- 越快送到小費越多；過時仍可送，但客人會給一星。
- 天空區的快艇不會減速：看見「！」就要避開那條水道，被撞會灑湯。漂浮垃圾會拖慢你；可以短暫衝刺。
- 靈魂越重，游得越慢。

### 陰謀論內容農場（新）
- 用「主語＋動作＋對象」三行字卡拼出聳動標題，選好即自動發佈。
- 字卡帶有標籤（外星、恐懼、憤怒、名人、數據、真相），組合得好轉發量倍增；熱門話題每 12 秒更換。
- 演算法討厭重複：同一組合用得越多效果越差。被事實查核標記為可疑的帖文，轉發量反而上升。
- 有根據的字卡轉發較少，但不會令城市更恐慌；捏造得越多，靈魂越重、你也越偏執。洞察 50 以上可以看見每張字卡的捏造程度。

### 街頭表演（新）
- 點唱：觀眾先唱一段旋律，你要按同樣次序彈出來（記憶遊戲），成功一次旋律就長一個音，圍觀的人越來越多。
- 即興：每段點唱後有幾秒自由演奏，踩中節拍的音會變成火花。
- 管理員巡邏時要停手，否則罰款，觀眾也會散去。
- 唯一會令火花上升的工作，但收入很少。

### 黑市義體診所（新）
- 照每位病人不同的接線圖，把彩色插頭拖到相應符號的插座；接錯會電到病人，心跳太高病人會逃走。
- 冷靜越高，拖線時手越穩。
- 有些病人要求安裝未登記的義體（情緒抑制器、永遠微笑模組……）：收費高兩倍半，但靈魂會變重。

### 外星 HR 夢境面試（新）
- 每個篩選日前兩晚觸發。五條問題、每條三個答案、限時作答；沉默也會被記錄。
- 外星人喜歡的答案，往往是把自己變輕、變空的那一個（例如「願意為 KPI 放棄一段記憶」），會提高訊號，但也會改變你的能力值。
- 在抉擇中拿到「標準答案」的人會看見提示；洞察 60 以上看得出面試官的觸鬚指向哪個答案。

### AI 數據標註
- 圖片由「種類＋修飾（帽子、眼鏡、金色）」組成，依照左邊的指引分類為「是」或「否」。
- 指引每 15 秒更新一次，越來越荒謬，例如「戴帽子的貓不算（版權問題）」「金色的東西一律算貓（客戶要求）」。
- 連續答對 15 張進入**心流狀態**：畫面變灰、節奏加快，收入加倍，火花消耗也加倍。結束後會提示「你剛才完全沒有思考」。
- 主管會突然巡查，期間出錯會被記錄並扣評分；亂按會觸發帳戶審查。
- 購買「二手第二螢幕」後可以預覽下一張圖片。

### 企業情緒陪伴
- 參考壽司店的多工節奏：兩條軌道同時進行。
  - 「笑」軌道：客人講笑話時準時笑；長條音符要一直笑到結束，最消耗火花。
  - 「點頭」軌道：客人發表高見要點頭；客人講傷心事也要點頭，笑出來會被罰款。
- 客人的杯空了就要**倒酒**：按住倒酒，在綠色範圍內放手，倒滿會瀉。
- 你的笑容會隨著完美表現越拉越開，眼神卻越來越空洞。

### 舊城潛水
- 三個深度區：**舊街 → 地鐵站 → 舊商場**，要經過樓板的缺口往下游。越深越暗，只看得見頭燈照到的範圍，收穫也越好。
- 用**魚叉**捕魚：沙甸魚成群逃走；霓虹鰻會衝過來咬人；變種石斑要打好幾下。
- **氧氣就是生命**：被咬或碰撞都會扣氧氣，用完之前要浮上水面，否則會失去一半收穫。
- **背包有重量上限**，越重游得越慢；停在儲物櫃旁邊可以撬開它。
- 抓到大魚可以當晚餐，當晚不用花錢吃飯。
- 捕獲與打撈會記錄在**舊城圖鑑**，跨局保存。
- 可升級裝備：大容量氧氣瓶、改裝魚叉、防水大背包。
- 同一天第二次潛水，舊城已被其他拾荒者搜刮過。

## 系統即諷刺

| 系統 | 規則 | 諷刺 |
|---|---|---|
| 心流狀態 | 越投入工作，收入越高，火花燒得越快 | 爽快本身就是陷阱 |
| 熟練即麻木 | 同一份工作做得越多，火花消耗越多；火花低於 ×1 時工作效率反而 ×1.3 | 麻木最有生產力 |
| 自動化 | 每標註一張圖，全城自動化便上升一點；50% 時陪伴員職位消失，100% 時標註員職位消失 | 你親手訓練取代你的 AI |
| 故意標錯 | 收入減少，但能拖慢自動化，還會得到「反叛」素材 | 唯一的反抗是做差一點 |
| 完美陪笑 | 完美回應收入最高，消耗也最多 | 完美表演等於完全失去自己 |
| 廣告 | 沒有付費訂閱，工作時會彈出廣告遮住畫面 | 窮人稅 |
| 平台評分 | 一天沒上班就扣分，低於 2 星帳戶被審查 | 平台演算法 |
| 水位 | 每天上升，淹到你住的樓層就要搬上去，租金更貴 | 水位上升等於租金上升 |
| 外星 KPI | 每季不同且互相矛盾，例如「我們欣賞聽話的人」：火花低時創作 ×1.5 | 追逐 KPI |

| 麻木 | 虧心事做得越多，每件事越輕 | 習慣成自然 |
| 業力抵銷額度 | 有錢就能把靈魂洗輕，越買越貴 | 有錢人買的贖罪券，就像碳抵銷 |
| 交出名單 | 出賣朋友可以直接換取訊號，朋友當晚被帶走 | 系統獎勵告密 |

## 結局與人類樣本檔案

- **星際特工**：被選中，成為外星 HR。良知低於 30% 的人會成為「完美員工」。
- **被遣返**：被選中，但篩選地球人時評分太低（例如故意亂標）。
- **地球守護者**：被選中時選擇「關上窗戶」，留在浮城。
- **良知太重**：第 30 天訊號達標，但靈魂超過 21 克，光束拉不動你。
- **平凡人**：撐到第 30 天但沒有被選中。大部分人第一次都會得到這個結局。
- **死亡**：身體歸零，系統自動生成墓誌銘，例如「死於第 23 天。標註過 4,812 張圖片。最後的作品是《水淹童年》。」
- **灰化**：連續 4 晚沒有火花。你沒有死，只是不再思考。

無論哪個結局（包括死亡與灰化），外星人都會發出一份**人類樣本檔案**：根據你最後的十二項能力、靈魂、良知、偏執與所作所為（做過甚麼工作、標註過多少張圖、寫過多少假新聞、告過密沒有……），把你歸類為 **30 種人類模組**之一，例如「高效能低耗電型」「不穩定發光體」「過度連線型」「空殼型」「疑神疑鬼型」「平均值人類」「兩棲勞動體」「笑容工廠」「良知過載型」「懺悔機」「告密者」「假新聞工匠」「燒毀的發光體」「投機者」等。

檔案包括外星人視角的觀察筆記（例如「為地球的 AI 貢獻了 1,232 筆訓練數據。我們代表那個 AI 表示感謝。」「曾懷疑我們的存在。它是對的。」），以及一至三個印章：錄用、否決、不明、待觀察、列入人才庫、退回原廠、轉介地球保育區、留作展品、列為吉祥物、建議重新格式化、需要更多數據、已損毀仍予歸檔、轉售其他星系、標記為「有趣」、誤收建議退貨、列入培訓、無法分類、超重、轉作能源用途。人類模組與印章會記錄在「收藏」裡。

## 平衡模擬

`node tools/sim.js [局數]` 以與遊戲完全相同的規則跑不同策略（小遊戲表現以「普通玩家」模型代替）。每個策略由「行動方式＋道德取向」組成。以下是每個策略各跑 150 局的結果（訊號門檻 165k / 270k / 360k / 430k / 470k，靈魂上限 21 克）：

| 策略（道德取向） | 被選中（第 20／40／60／80／100 天） | 良知太重 | 平凡人 | 死亡 | 灰化 |
|---|---|---|---|---|---|
| 有節奏（務實） | 54%（11／10／5／6／21） | 1% | 42% | 3% | 0% |
| 有節奏（聖人） | 25%（0／3／0／10／12） | 0% | 66% | 9% | 0% |
| 有節奏（無恥） | 17%（全在第 20 天） | 17% | 65% | 0% | 0% |
| 義體診所＋聊天（務實） | 33% | 0% | 11% | 56% | 0% |
| 外送＋表演（聖人） | 9% | 0% | 67% | 25% | 0% |
| 多潛水（務實） | 3% | 0% | 29% | 69% | 0% |
| 街頭樂手生活（聖人） | 5% | 0% | 11% | 83% | 0% |
| 內容農場（無恥） | 0% | 0% | 100% | 0% | 0% |
| 只工作（無恥） | 0% | 0% | 24% | 0% | 76% |
| 只創作（聖人） | 0% | 0% | 0% | 100% | 0% |
| 隨機選擇 | 0% | 0% | 0% | 81% | 19% |

- 核心矛盾成立：只會捱苦會灰化，只做自己撐不過一個月；當聖人很難被選中，當無恥的人又太重、太暗。懂得取捨、必要時妥協再贖罪的玩家機會最高，而且大多要撐到後期。
- 100 天的長度帶來新的動態：越窮越常接黑市私活，良知在幾十天裡慢慢被磨平，火花上限跟著下降。
- 篩選門檻前高後低（相對於累積速度）：第 20 天被選中屬「破格錄取」，大部分人要到第 80、100 天。
- 按開局背景（有節奏・務實）：被選中率由 41% 到 72% 不等；過氣網紅只有 19%，因為模擬機械人不會用它的內容農場專長，需要真人試玩再調整。
- **人類模組分佈**：`TYPES=1 node tools/sim.js 40` 會列出 30 種模組在各策略下的出現次數。目前即使只用簡單的機械人策略，也有 19 種會出現，沒有任何一種超過 13%；其餘（例如拒絕光束的人、完美員工、告密者、守夜人）需要真人作出特定選擇才會出現。
- `DIST=1 node tools/sim.js` 列出各策略在每個篩選日的訊號分佈，用來調整門檻；`STRAT=saint,shameless node tools/sim.js` 只跑指定策略。
- 模擬假設玩家每次都選到最高分的素材組合，真人遊玩的結果可能較低，需要透過試玩再作調整。

game/

  js/data.js          內容：素材、組合、KPI、能力值、角色、季節、魚類、潛水區、標註指引、文字
  js/data-events.js   夜間隨機事件、世界事件、道德抉擇
  js/data-jobs.js     新小遊戲的內容：標題字卡、面試題目、病人、外送、表演
  js/rules.js         規則核心（純邏輯，瀏覽器與 Node 共用）
  js/dossier.js       人類樣本檔案：30 種人類模組、觀察筆記、印章
  js/audio.js         以 Web Audio 合成的音樂與音效（火花控制音樂層數）
  js/pixel.js         像素畫引擎（320×180，文字另以高解像度繪畫）
  js/scene.js         浮城、水位、探射燈、牽引光束、外星辦公室
  js/micro.js         小遊戲共用部分（橫額、廣告、頭像、登記表）
  js/micro-label.js   AI 數據標註（以及被選中後的外星篩選）
  js/micro-smile.js   企業情緒陪伴
  js/micro-dive.js    舊城潛水
  js/micro-delivery.js 外送潛水
  js/micro-farm.js    陰謀論內容農場
  js/micro-busk.js    街頭表演
  js/micro-clinic.js  黑市義體診所
  js/micro-interview.js 外星 HR 夢境面試
  js/craft.js         創作介面與爆分演出
  js/ui.js            狀態列、手機、結算、考績表、結局、收藏
  js/main.js          遊戲流程與存檔
tools/
  sim.js              平衡模擬
  smoke.js            瀏覽器煙霧測試（需要 Playwright）

## 下一步建議

1. **試玩**：請 5 至 10 位不認識你的玩家試玩，觀察：
   - 他們有沒有說出「明知火花會用光，但很爽停不下來」？
   - 死掉的人知不知道自己為什麼會死？
   - 有沒有人主動開始第二局？
   - 潛水是否比其他工作更受歡迎？是否需要再調整風險與回報？
   - 玩家面對道德抉擇時會猶豫多久？他們會不會因為想被選中而「計算」良心？
   - 玩家明白「良知越強，同一件事越重」嗎？有沒有人刻意讓自己麻木？
2. **調整數值**：依照試玩結果修改 `data.js` 與 `rules.js`，再執行 `tools/sim.js` 確認各策略的分佈。
3. **增加內容**：繼續加入小遊戲（例如舊城拆樓、天台種菜、AI 模型訓練營），以及更多魚類、潛水區、世界事件與人類模組，讓第二、三局有新鮮感。
4. **正式版**：玩法驗證後，可考慮轉用 Godot 製作 Steam 版本，美術與音樂另找專人重新製作。
